在全国硕士研究生招生考试计算机学科专业基础综合（408）试卷中，【网络号和主机号】是网络层乃至整个计算机网络大纲中出现频次最高、覆盖面最广的核心基石考点之一。

### 2. 命题特点分析
1. **位级运算考查深入**：题目极少考查纯粹死记硬背的文字概念，而是深度结合二进制按位“与”（AND）、按位“或”（OR）、按位“取反”（NOT）等逻辑运算，考查网络前缀边界的十进制换算。
2. **特殊 IP 地址语义约束**：重点考查各类特殊 IP 地址（如受限广播地址、直接广播地址、本网络本主机地址、环回测试地址等）在数据报首部作为“源 IP 地址”和“目的 IP 地址”的语法合法性及路由器转发行为。
3. **子网借位及可用容量折损**：考查向主机号借位划分子网时，每个子网内网络地址（主机号全 0）和直接广播地址（主机号全 1）对可分配主机数量的扣除规则（$2^h - 2$ 规则）。
4. **跨协议及网络拓扑联动**：在选择题和综合解答大题中，常将点对点链路（`/30` 网段）、默认网关分配、NAT 网络地址转换、CIDR 路由聚合及 ARP/DHCP 协议流程紧密交织在一起。

## 二、 具体考察内容

### 1. IPv4 地址的双层结构和数学模型

#### (1) 基本概念
IPv4 地址由 32 位二进制比特组成，在逻辑上分为两个层级：
- **网络号（Net-ID）**：标识一个物理网络或逻辑子网，在同一个局域网内所有主机的网络号必须严格相同。
- **主机号（Host-ID）**：标识该特定网络内的一台物理主机或路由器接口，在同一网络内部必须具有唯一性。

随着网络技术演进，IP 编址经历了三个发展阶段：
1. **两级分类 IP 地址**：$\text{IP 地址} = \{\langle \text{Net-ID}\rangle, \langle \text{Host-ID}\rangle\}$
2. **三级子网划分 IP 地址**：$\text{IP 地址} = \{\langle \text{Net-ID}\rangle, \langle \text{Subnet-ID}\rangle, \langle \text{Host-ID}\rangle\}$
3. **无分类编址 CIDR**：$\text{IP 地址} = \{\langle \text{Prefix}\rangle, \langle \text{Host-ID}\rangle\}$，记为 $\text{IP 地址}/\text{Prefix}$。

#### (2) 子网掩码及布尔位运算推导
子网掩码（Subnet Mask）是一个长度为 32 位的二进制数，其高位连续为 1，对应网络前缀（网络号及子网号），低位连续为 0，对应主机号。

设某主机的 IPv4 地址为 $A$，子网掩码为 $M$：
1. **网络地址（Network Address）推导**：
   $$\text{Net\_Addr} = A \land M$$
   其中 $\land$ 表示按位逻辑与（Bitwise AND）。该运算将主机号部分全部强制清零，保留网络前缀。
2. **直接广播地址（Directed Broadcast Address）推导**：
   $$\text{Brd\_Addr} = A \lor (\neg M)$$
   其中 $\lor$ 表示按位逻辑或（Bitwise OR），$\neg$ 表示按位取反（Bitwise NOT）。该运算将主机号部分全部强制置 1。
3. **主机号（Host-ID）数值提取**：
   $$\text{Host\_ID} = A \land (\neg M)$$
   该运算将网络前缀清零，直接提取出该地址在子网内的主机偏移量。

#### (3) 掩码字节速算映射表
IPv4 地址以点分十进制表示，每个字节对应 8 位二进制。子网划分时，关键计算均发生在掩码中最后一个非 0 或非 255 的字节：

```text
+----------+---------------+----------------+------------+
| 借位位数 | 二进制末字节  | 十进制数值     | 块大小步长 |
+----------+---------------+----------------+------------+
| 0        | 0000 0000     | 0              | 256        |
| 1        | 1000 0000     | 128            | 128        |
| 2        | 1100 0000     | 192            | 64         |
| 3        | 1110 0000     | 224            | 32         |
| 4        | 1111 0000     | 240            | 16         |
| 5        | 1111 1000     | 248            | 8          |
| 6        | 1111 1100     | 252            | 4          |
| 7        | 1111 1110     | 254            | 2          |
| 8        | 1111 1111     | 255            | 1          |
+----------+---------------+----------------+------------+
```
> **数学规律**：块大小（即每个子网在该字节上的跨度）$\Delta = 256 - \text{掩码字节值} = 2^{8-k}$，其中 $k$ 为该字节内掩码中 `1` 的个数。

### 2. 分类 IP 地址体系

早期 IPv4 体系采用固定边界的分类编址（Classful Addressing），依据最高前缀比特划分为 A、B、C、D、E 五大类别：

```text
A类: 0  |-- 7位网络号 --|------------- 24位主机号 -------------|
B类: 10 |-- 14位网络号 --------|------ 16位主机号 ------|
C类: 110|-- 21位网络号 ------------------|-- 8位主机号 -|
D类: 1110|------------- 28位多播组标识符 ---------------|
E类: 1111|------------- 28位科研保留 -------------------|
```

#### (1) A 类地址
- **最高比特**：以 `0` 开头。
- **网络号所占位数**：8 位（1 字节）。
- **主机号所占位数**：24 位（3 字节）。
- **第一字节范围**：二进制 `0000 0001` ~ `0111 1110`，即十进制 $1 \sim 126$。
- **网络总数推导**：
  $$N_{\text{net}} = 2^7 - 2 = 126$$
  *扣除依据*：全 0 网络号 `0.0.0.0` 保留表示本网络；`0111 1111` 即十进制 127 保留作为环回测试（Loopback）。
- **每个网络最大可用主机数**：
  $$N_{\text{host}} = 2^{24} - 2 = 16,777,214$$
  *扣除依据*：扣除主机号全 0 的网络地址和主机号全 1 的直接广播地址。

#### (2) B 类地址
- **最高比特**：以 `10` 开头。
- **网络号所占位数**：16 位（2 字节）。
- **主机号所占位数**：16 位（2 字节）。
- **第一字节范围**：二进制 `1000 0000` ~ `1011 1111`，即十进制 $128 \sim 191$。
- **网络总数推导**：
  $$N_{\text{net}} = 2^{14} = 16,384$$
  *注意*：RFC 规范中 B 类网络号 `128.0` 规定为保留（早先规范），但现代标准下整个 $128.0 \sim 191.255$ 均全量可分配，408 统考中严格认定 B 类网络总数为 $2^{14}$。
- **每个网络最大可用主机数**：
  $$N_{\text{host}} = 2^{16} - 2 = 65,534$$

#### (3) C 类地址
- **最高比特**：以 `110` 开头。
- **网络号所占位数**：24 位（3 字节）。
- **主机号所占位数**：8 位（1 字节）。
- **第一字节范围**：二进制 `1100 0000` ~ `1101 1111`，即十进制 $192 \sim 223$。
- **网络总数推导**：
  $$N_{\text{net}} = 2^{21} = 2,097,152$$
- **每个网络最大可用主机数**：
  $$N_{\text{host}} = 2^8 - 2 = 254$$

#### (4) D 类和 E 类地址
- **D 类地址（组播地址）**：以 `1110` 开头，第一字节范围 $224 \sim 239$。用于单对多组播传输，不存在网络号和主机号概念，不能分配给具体主机网卡。
- **E 类地址（保留地址）**：以 `1111` 开头，第一字节范围 $240 \sim 255$。保留用于科学研究和未来扩展。

### 3. 特殊 IP 地址全谱系剖析

特殊 IP 地址是 408 命题中的高危陷阱。下表系统归纳了所有特殊 IP 地址的技术特征、源/目的合法性以及路由器转发行为：

```text
+-----------------------+---------------------+---------------+--------------------+------------+------------+--------------+
| 地址类型名称          | 典型点分十进制表示  | 网络号特征    | 主机号特征         | 作源地址   | 作目的地址 | 路由器转发   |
+-----------------------+---------------------+---------------+--------------------+------------+------------+--------------+
| 本网络本主机          | 0.0.0.0/32          | 全 0          | 全 0               | 允许       | 禁止       | 严禁转发     |
| 默认路由指向          | 0.0.0.0/0           | 全 0 (前缀0)  | 全 0               | 仅用于路由表匹配，不出现在分组首部        |
| 本网络上的特定主机    | 0.Host-ID           | 全 0          | 特定主机号         | 允许       | 允许(局域) | 严禁转发     |
| 受限广播地址          | 255.255.255.255     | 全 1          | 全 1               | 禁止       | 允许       | 严禁转发     |
| 直接广播地址          | Net-ID.255.255...   | 特定网络号    | 全 1               | 禁止       | 允许       | 默认不转发   |
| 网络地址 (网段标识)   | Net-ID.0.0...       | 特定网络号    | 全 0               | 禁止       | 禁止       | 不适用(网段) |
| 环回测试地址          | 127.0.0.0/8         | 01111111 (127)| 任意非全0非全1值   | 允许       | 允许       | 绝不上物理线 |
| 链路本地地址 (APIPA)  | 169.254.0.0/16      | 169.254       | 随机自动生成       | 允许       | 允许       | 严禁跨路由   |
+-----------------------+---------------------+---------------+--------------------+------------+------------+--------------+
```

#### (1) 本网络本主机（$0.0.0.0$）
- **功能定位**：当一台主机刚刚加电启动、尚未通过 DHCP 协议获取到合法 IP 地址时，在发送“DHCP 发现报文”（DHCP Discover）时，无法填写自身源 IP 地址，此时强制使用 $0.0.0.0$ 作为源 IP 地址。
- **权限边界**：**只能作为源 IP 地址，绝对不能作为目的 IP 地址**。任何收到目的 IP 为 $0.0.0.0$ 的主机或路由器均会直接丢弃该分组。

#### (2) 受限广播地址（$255.255.255.255$）
- **功能定位**：用于在本地物理网段内进行无差别二层及三层广播（例如未配 IP 时向全网寻找 DHCP 服务器）。
- **权限边界**：**只能作为目的 IP 地址，绝对不能作为源 IP 地址**。
- **转发特性**：受限广播被严格限制在源节点所在的广播域内部，**任何路由器绝对不转发受限广播**。

#### (3) 直接广播地址（Directed Broadcast Address）
- **功能定位**：主机号字段全为 1（如 $192.168.1.255$）。用于向指定网络号所在网段内的所有主机发送广播。
- **权限边界**：**只能作为目的 IP 地址，不能作为源 IP 地址**。
- **转发特性**：理论上路由器允许在公网上转发该分组至目标子网路由器的入接口，再在目标子网内爆发为局域广播；但在现代网络工程中，为防止 Smurf 放大拒绝服务攻击，边界路由器默认全面禁用定向广播转发。

#### (4) 环回测试地址（$127.0.0.0/8$）
- **功能定位**：网络号规定为 127。最常用的是 $127.0.0.1$（`localhost`）。用于本机操作系统内部各进程间的网络通信测试。
- **转发特性**：操作系统的网络驱动层在检测到目的地址为 127 网段时，会直接将数据报环回送往本机传输层协议栈，**该 IP 分组绝不会出现在任何物理传输介质上**。可以同时作为源 IP 地址和目的 IP 地址。

#### (5) 私有 IP 地址块（Private Addressing, RFC 1918）
为解决 IPv4 地址枯竭，IANA 保留了三段专用内部地址，不可在公网路由上出现：
- **A 类私网**：$10.0.0.0 \sim 10.255.255.255$（即 $10.0.0.0/8$），共计 1 个 A 类网络。
- **B 类私网**：$172.16.0.0 \sim 172.31.255.255$（即 $172.16.0.0/12$），连续包含 16 个 B 类网络（$172.16$ 到 $172.31$）。
- **C 类私网**：$192.168.0.0 \sim 192.168.255.255$（即 $192.168.0.0/16$），连续包含 256 个 C 类网络（$192.168.0$ 到 $192.168.255$）。

> **核心判定**：若局域网内部主机使用私有 IP 地址，访问 Internet 公网服务器时必须经过 NAT（网络地址转换）路由器，将其源 IP 地址替换为合法的公网 IP 地址。

### 4. 主机号借位及子网划分推导

#### (1) 子网借位数学模型
当一个拥有网络前缀长度为 $L_{\text{old}}$ 的网络需要被划分为规模更小的逻辑子网时，必须从原本的主机号高位中借调 $s$ 位充当“子网号”（Subnet-ID）：

```text
原始网络: |------- 原前缀 L_old -------|---------- 原主机号 H_old ----------|
子网划分: |------- 原前缀 L_old -------|-- 借位 s --|--- 剩余主机号 h ---|
新网络前缀: |<---------- 新前缀 L_new = L_old + s --------->|
```

各数学参量之间的约束关系如下：
1. **新网络前缀长度**：
   $$L_{\text{new}} = L_{\text{old}} + s$$
2. **剩余主机号位数**：
   $$h = 32 - L_{\text{new}} = H_{\text{old}} - s$$
3. **划分出的子网总数**：
   $$N_{\text{subnet}} = 2^s$$
   > **规范说明**：在 CIDR 和 RFC 1812 现代路由器规范下，子网号允许全 0 和全 1。408 统考中默认全 0 和全 1 子网均完全合法并正常计入子网总数。
4. **每个子网包含的总 IP 数量**：
   $$N_{\text{total\_IP}} = 2^h$$
5. **每个子网最大可分配的主机 IP 数量**：
   $$N_{\text{usable\_IP}} = 2^h - 2$$
   *扣除项目*：
   - 主机号全 0 的地址：用作子网本身的**网络地址**（Network Address）。
   - 主机号全 1 的地址：用作子网内部的**直接广播地址**（Directed Broadcast Address）。

#### (2) 子网区间及可用主机地址推导四步法
给定任意子网地址块 $\text{Base}/\text{Prefix}$，推导步骤如下：
1. **求剩余主机位数**：$h = 32 - \text{Prefix}$。
2. **求地址块步长（总容量）**：$\Delta = 2^h$。
3. **求直接广播地址**：
   $$\text{Broadcast} = \text{Network} + \Delta - 1$$
4. **求可分配地址闭区间**：
   $$[\text{Host}_{\min}, \text{Host}_{\max}] = [\text{Network} + 1, \text{Broadcast} - 1]$$

#### (3) 关键特殊掩码剖析
- **`/30` 掩码（$255.255.255.252$）**：
  $h = 32 - 30 = 2$。总 IP 数为 $2^2 = 4$ 个。最大可用主机地址数为 $2^2 - 2 = 2$ 个。在实际网络工程和 408 考题中，`/30` 是**路由器之间点对点串行链路的标准互联掩码**（恰好容纳链路两端的两个路由器接口，无多余地址浪费）。
- **`/31` 掩码（$255.255.255.254$）**：
  $h = 32 - 31 = 1$。按传统规则可分配地址数为 $2^1 - 2 = 0$。虽然 RFC 3021 提出了无广播点对点链路标准，但在 408 考试理论体系中，一律严格判定 `/31` 无法分配给普通主机或路由器接口。
- **`/32` 掩码（$255.255.255.255$）**：
  $h = 0$。表示精确到单个特定主机的“主机路由”（Host Route），常见于路由表最精确匹配或 Loopback 虚拟接口配置。

## 三、 近十年真题精讲（2016~2025）

### 1. 2023 年 408 真题第 39 题
**【题目】**  
主机 168.16.84.24/20 所在子网的最小可分配地址和最大可分配地址分别是（ ）。  
A. 168.16.80.1，168.16.84.254  
B. 168.16.80.1，168.16.95.254  
C. 168.16.84.1，168.16.84.254  
D. 168.16.84.1，168.16.95.254  

**【深度解析】**  
第一步：分析网络前缀和主机号位宽。  
网络前缀为 $/20$，因此前 20 位为网络前缀，剩余主机号位数 $h = 32 - 20 = 12$ 位。  
前 20 位跨越两个半字节：第 1、2 字节全部为网络前缀（16 位），第 3 字节占用高 4 位（$16 + 4 = 20$），第 3 字节低 4 位及第 4 字节（共 $4 + 8 = 12$ 位）构成主机号。

第二步：对变化的第 3 字节展开二进制分析。  
主机 IP 为 $168.16.84.24$。  
第 3 字节数值为十进制 84，转换为 8 位二进制：
$$84 = 64 + 16 + 4 = (0101 \ 0100)_2$$
划分子网界线（高 4 位为网络前缀，低 4 位为主机号）：
$$0101 \ \big| \ 0100$$
高 4 位前缀固定为 `0101`。

第三步：计算网络地址和广播地址。
- **网络地址（主机号全 0）**：
  第 3 字节低 4 位全置 0，得到 $(0101 \ 0000)_2 = 64 + 16 = 80$。
  第 4 字节 8 位主机号全置 0，得到 0。
  故网络地址为：$168.16.80.0$。
- **直接广播地址（主机号全 1）**：
  第 3 字节低 4 位全置 1，得到 $(0101 \ 1111)_2 = 64 + 16 + 15 = 95$。
  第 4 字节 8 位主机号全置 1，得到 255。
  故广播地址为：$168.16.95.255$。

第四步：求解可分配主机地址范围。
- 最小可分配地址：网络地址 $+ 1 \Rightarrow 168.16.80.1$。
- 最大可分配地址：直接广播地址 $- 1 \Rightarrow 168.16.95.254$。

对照选项，选项 B 完全正确。

**【正确答案】**：**B**

### 2. 2022 年 408 真题第 35 题
**【题目】**  
若某主机的 IP 地址是 183.80.72.48，子网掩码是 255.255.192.0，则该主机所在网络的网络地址是（ ）。  
A. 183.80.0.0  
B. 183.80.64.0  
C. 183.80.72.0  
D. 183.80.192.0  

**【深度解析】**  
第一步：对比 IP 地址和子网掩码各字节。  
- IP 地址：$183 \ . \ 80 \ . \ 72 \ . \ 48$  
- 掩码：$255 \ . \ 255 \ . \ 192 \ . \ 0$  
显然，前两个字节掩码全为 255，按位与后保持原样 $183.80$；第四字节掩码全为 0，按位与后结果必为 0。计算焦点完全聚焦在第 3 字节。

第二步：针对第 3 字节进行按位逻辑与（AND）运算。  
- IP 第 3 字节数值 $72 = 64 + 8 = (0100 \ 1000)_2$  
- 掩码第 3 字节数值 $192 = 128 + 64 = (1100 \ 0000)_2$  
逐位相与：
```text
  0100 1000  (72)
& 1100 0000  (192)
-------------------
  0100 0000  (64)
```
第三步：合并得到网络地址。  
将各字节组合，最终得到网络地址为：$183.80.64.0$。  
对应选项 B。

**【正确答案】**：**B**

### 3. 2017 年 408 真题第 36 题
**【题目】**  
下列 IP 地址中，只能作为 IP 分组的源 IP 地址但不能作为目的 IP 地址的是（ ）。  
A. 0.0.0.0  
B. 127.0.0.1  
C. 200.10.10.3  
D. 255.255.255.255  

**【深度解析】**  
逐项剖析各特殊 IP 地址的协议规范和语法约束：
- **A 选项（0.0.0.0）**：表示“本网络上的本主机”。在主机未配置 IP 地址时（如处于 DHCP 发现阶段），必须以此作为 IP 数据报首部的源 IP 地址；根据 RFC 规范，任何节点严禁以 $0.0.0.0$ 作为目的 IP 地址发送分组，收到目的 IP 为 $0.0.0.0$ 的报文将被直接丢弃。因此它只能作源地址，不能作目的地址。A 正确。
- **B 选项（127.0.0.1）**：属于环回测试地址（Loopback）。本机进程间通信时，既可以作为源 IP 地址，也可以作为目的 IP 地址（例如 `ping 127.0.0.1` 或访问本地 Web 服务 `http://127.0.0.1:8080`）。B 错误。
- **C 选项（200.10.10.3）**：属于合法的单播 C 类 IP 地址（$192 \le 200 \le 223$）。单播地址既可以作为源 IP 地址（发送方主机），也可以作为目的 IP 地址（接收方主机）。C 错误。
- **D 选项（255.255.255.255）**：属于受限广播地址。该地址专门用于向本物理网络内的所有主机广播数据，**只能作为目的 IP 地址，严禁作为源 IP 地址**（任何节点的源 IP 绝不能是广播地址）。该选项跟题意要求恰好相反。D 错误。

**【正确答案】**：**A**

### 4. 2017 年 408 真题第 38 题
**【题目】**  
若将网络 21.3.0.0/16 划分为 128 个规模相同的子网，则每个子网可分配的最大 IP 地址个数是（ ）。  
A. 254  
B. 256  
C. 510  
D. 512  

**【深度解析】**  
第一步：求向主机号借用的子网位数 $s$。  
原始网络前缀为 $/16$，说明原主机号位数为 $H = 32 - 16 = 16$ 位。  
要划分为 128 个规模相同的子网，需满足：
$$2^s = 128 \implies s = 7$$
即需要从 16 位主机号的高位中借出 7 位作为子网号。

第二步：求每个子网剩余的主机号位数 $h$。  
剩余主机号位数：
$$h = H - s = 16 - 7 = 9\text{ 位}$$

第三步：计算每个子网最大可分配的主机 IP 地址数。  
对于长度为 $h = 9$ 位的主机号：
- 该子网拥有的 IP 地址总容量为 $2^9 = 512$ 个。
- 扣除主机号全 0 的子网网络地址（1 个）。
- 扣除主机号全 1 的子网直接广播地址（1 个）。
最大可分配主机 IP 地址数为：
$$N_{\text{usable}} = 2^9 - 2 = 512 - 2 = 510$$
选项 C 正确。

> **陷阱警示**：选项 D 的 512 是每个子网的 IP 地址总数；题目明确询问“可分配的最大 IP 地址个数”，必须严格扣除网络地址和广播地址。

**【正确答案】**：**C**

### 5. 2016 年 408 真题第 38 题
**【题目】**  
假设连接 R1、R2 和 R3 之间的点对点链路使用 201.1.3.x/30 地址，当 H3 访问 Web 服务器 S 时，R2 转发出去的封装 HTTP 请求报文的 IP 分组的源 IP 地址和目的 IP 地址分别是（ ）。  
A. 192.168.3.251，130.18.10.1  
B. 192.168.3.251，201.1.3.9  
C. 201.1.3.8，130.18.10.1  
D. 201.1.3.10，130.18.10.1  

**【深度解析】**  
本题是 408 历史上最为经典的一道将【`/30` 子网主机号分配】和【NAT 网络地址转换机制】深度融合的综合题目。

第一步：解析 `/30` 互联链路的地址结构。  
题干给出 R1、R2 和 R3 之间的点对点链路使用 $201.1.3.x/30$ 地址。  
$/30$ 掩码即 $255.255.255.252$，主机号长度仅为 $32 - 30 = 2$ 位。  
结合真题拓扑已知条件，R1 的一个互联接口 IP 标注为 $201.1.3.9$。  
分析 $201.1.3.9$ 所在的 `/30` 子网：
- 末字节数值 $9 = (0000 \ 1001)_2$。
- 主机号为后 2 位，即二进制 `01`。
- 将后 2 位置 0，得到子网网络地址：末字节为 $(0000 \ 1000)_2 = 8$，即 $201.1.3.8/30$。
- 将后 2 位置 1，得到直接广播地址：末字节为 $(0000 \ 1011)_2 = 11$，即 $201.1.3.11/30$。
- 该子网中仅有的两个合法可用主机地址为：
  - 第一个可用地址：$201.1.3.8 + 1 = 201.1.3.9$（已分配给 R1）。
  - 第二个可用地址：$201.1.3.8 + 2 = 201.1.3.10$。
因此，该点对点链路对端 R2 的出口接口 IP 地址必须且只能是 $201.1.3.10$。

第二步：分析 NAT 转换机制对分组首部 IP 地址的影响。  
拓扑中主机 H3 的 IP 为局域网私有地址（$192.168.3.251$），Web 服务器 S 的 IP 为外网公网地址（$130.18.10.1$）。  
私有 IP 地址不能在公网中路由。当 H3 发送的 HTTP 请求经过作为 NAT 网关的路由器 R2 时，R2 必须执行源网络地址转换（SNAT）：
- **源 IP 地址**：被 R2 替换为本路由器连接外网的点对点接口公网 IP 地址，即 $201.1.3.10$。
- **目的 IP 地址**：端到端寻址目标不变，始终为 Web 服务器 S 的地址 $130.18.10.1$。

第三步：排除错误选项。  
- 选项 A 未考虑 NAT 地址转换，源地址保留私网 IP 错误；  
- 选项 B 将目的地址误写为对端路由器接口；  
- 选项 C 中 $201.1.3.8$ 为主机号全 0 的网络地址，绝对不能分配给物理接口。  
只有选项 D 完全吻合。

**【正确答案】**：**D**

### 6. 经典真题回溯：2012 年 408 真题第 39 题
**【题目】**  
某主机的 IP 地址为 180.80.77.55，子网掩码为 255.255.252.0。若该主机向其所在子网发送广播分组，则目的地址可以是（ ）。  
A. 180.80.76.0  
B. 180.80.76.255  
C. 180.80.77.255  
D. 180.80.79.255  

**【深度解析】**  
第一步：分析子网掩码确定前缀长度和主机号位数。  
掩码为 $255.255.252.0$。  
- 前两个字节均为 255（16 位）；  
- 第 3 字节 $252 = 128 + 64 + 32 + 16 + 8 + 4 = (1111 \ 1100)_2$，高 6 位为 1；  
- 故网络前缀总长度为 $16 + 6 = 22$ 位，主机号长度为 $32 - 22 = 10$ 位（包括第 3 字节低 2 位及第 4 字节全部 8 位）。

第二步：展开 IP 地址第 3 字节并计算直接广播地址。  
- IP 地址第 3 字节数值 $77 = 64 + 8 + 4 + 1 = (0100 \ 1101)_2$。  
- 掩码第 3 字节为 $(1111 \ 1100)_2$。  
广播地址需将主机号全部置 1：  
- 第 3 字节保留前 6 位前缀 `0100 11`，后 2 位强制置 `11`：
  $$(0100 \ 1111)_2 = 64 + 8 + 4 + 2 + 1 = 79$$
- 第 4 字节的 8 位主机号全部置 1，得到十进制 255。

第三步：合并结果。  
该子网的直接广播地址为：$180.80.79.255$。  
主机向所在子网发送定向广播分组时，目的 IP 地址填写该广播地址。对应选项 D。

**【正确答案】**：**D**

## 四、 综合解答题深度拓展（大题考法联动）

在 408 试卷的第 47 题（或第 43 题）综合应用大题中，【网络号和主机号】常作为跨协议、跨层次大型拓扑综合题的切入点和基础打分点。

### 1. 变长子网划分（VLSM）标准化求解流程
在大题中，题目通常给出一段较大的初始 CIDR 地址块（如 $192.168.1.0/24$），要求为拓扑中的多个局域网（LAN）和路由器间互联链路分配 IP 地址。

**解题四步法**：
1. **按需降序排列**：将所有待分配网段按照所需的主机 IP 数量从大到小严格排序（先满足大子网，再满足小子网，最后分配路由器间的点对点链路）。
2. **计算主机号位数 $h$**：
   若某 LAN 包含 $N$ 台主机，且该 LAN 必须接入路由器的一个接口充当默认网关，则总共需要可用 IP 数量为 $N + 1$。
   主机号位数 $h$ 必须满足不等式：
   $$2^h - 2 \ge N + 1 \implies 2^h \ge N + 3$$
3. **确定新网络前缀及块大小**：
   网络前缀为 $\text{Prefix} = 32 - h$，该子网占用的地址块大小 $\Delta = 2^h$。
4. **自基准地址顺次对齐切割**：
   新分配的子网基准网络地址，其数值必须能够被块大小 $\Delta$ 整除（即边界对齐原则）。

### 2. CIDR 路由汇聚（超网聚合）标准算法
大题常考查将多个路由器接口宣告的子网路由聚合为一条最优前缀，以减小骨干网路由表规模。

```text
聚合步骤：
子网 1: 192.168.0000 0000.0/24
子网 2: 192.168.0000 0001.0/24
子网 3: 192.168.0000 0010.0/24
子网 4: 192.168.0000 0011.0/24
------------------------------------------------
最长公共前缀: 192.168.0000 00 (共 22 位)
聚合超网地址: 192.168.0.0/22
```

> **失分避坑**：路由聚合容易引入“黑洞路由”或路由环路。若聚合后涵盖了拓扑中实际不存在的子网，必须在边界路由器上配置指向 `Null0` 的黑洞路由。

### 3. 跨层协议栈首部 IP 地址流转大题模型
当一台主机从开机到成功访问外部 Web 服务器，数据包在协议栈各层的地址封装演变如下：

```text
+-------------------+--------------------+--------------------+---------------------------------------+
| 阶段及协议事件    | 源 IP 地址         | 目的 IP 地址       | 核心机制解析                          |
+-------------------+--------------------+--------------------+---------------------------------------+
| 1. DHCP Discover  | 0.0.0.0            | 255.255.255.255    | 主机尚未获配 IP，广播寻找 DHCP 服务器 |
| 2. DHCP Offer     | DHCP 服务器单播/IP | 255.255.255.255/IP | 服务器分配 IP、子网掩码、默认网关     |
| 3. ARP 广播请求   | 主机获配 IP        | 默认网关接口 IP    | 解析网关 MAC，二层目的 MAC 为全 FF    |
| 4. 局域网内出站   | 主机私有 IP        | Web 服务器公网 IP  | 源/目的 IP 全程保持不变               |
| 5. 穿过 NAT 出口  | 路由器公网接口 IP  | Web 服务器公网 IP  | 路由器执行源 NAT，替换源 IP 及源端口  |
| 6. 服务器回包     | Web 服务器公网 IP  | 路由器公网接口 IP  | 目的地为 NAT 外网口，NAT 转换表还原   |
+-------------------+--------------------+--------------------+---------------------------------------+
```

### 4. 综合大题四大致命失分陷阱
1. **网关接口漏算陷阱**：题目要求“LAN1 包含 60 台主机”，在计算 IP 需求量时，很多考生只按 60 计算（$2^6 - 2 = 62 \ge 60$ 选 $h=6$），却遗漏了该网段中**路由器的 LAN 接口必须占用 1 个可用 IP**。实际需求为 $60 + 1 = 61$，虽然在此题中 $62 \ge 61$ 恰好通过，但若需求是 62 台主机，漏算网关将导致 $62 + 1 = 63 > 62$，直接选错主机号位数致全题失分！
2. **点对点互联链路掩码陷阱**：路由器 R1 和 R2 之间互联时，有些考生随意分配一个 `/24` 子网，造成地址极大浪费而扣分；标准规范下必须分配 `/30` 掩码。
3. **网络号全 0 和全 1 误作主机分配**：直接将网络地址（如 $192.168.1.0$）或广播地址（如 $192.168.1.63$）配置给主机网卡或路由器接口，在阅卷中会被直接判 0 分。
4. **子网边界错位陷阱**：在划分变长子网时，前面的子网分配完毕后，下一个子网的网络地址必须是其自身块大小 $\Delta$ 的整数倍，不可紧贴前一个子网的任意奇数地址直接开始。

## 五、 考点速记清单

### 1. 核心解题口诀
- **掩码算块大小**：`256 减掩码值，就是步长子网块；下个网络加上块，广播减一不用猜。`
- **可用主机计算**：`主机位数为小 h，二的 h 次减去二；去掉全 0 网络号，去掉全 1 广播号。`
- **特殊地址权限**：`全零只能作源头，受限广播作目标；环回测试不走线，私网出境必 NAT。`

### 2. 避坑指南三铁律
1. **看到“可分配主机数”**：公式第一反应必写 $2^h - 2$；若问“IP 地址总数”才是 $2^h$。
2. **看到点对点链路**：掩码无脑锁定 `/30`（$255.255.255.252$），块大小为 4，可用主机数为 2。
3. **看到 $0.0.0.0$**：只准出现在源地址（DHCP 请求）或路由表条目（$0.0.0.0/0$ 默认路由），绝不能作为目的 IP 地址。

### 3. 高频掩码末字节速查表（背诵专用）

```text
+------+-------------------+------------+----------+------------+-----------------------+
| 前缀 | 掩码末字节 (十进制)| 块大小步长 | 总 IP 数 | 可用主机数 | 典型应用场景          |
+------+-------------------+------------+----------+------------+-----------------------+
| /24  | 0                 | 256        | 256      | 254        | 标准 C 类网段/大型 LAN|
| /25  | 128               | 128        | 128      | 126        | 容纳 120 台主机 LAN   |
| /26  | 192               | 64         | 64       | 62         | 容纳 50~60 台主机 LAN |
| /27  | 224               | 32         | 32       | 30         | 容纳 20~30 台主机 LAN |
| /28  | 240               | 16         | 16       | 14         | 小型部门/服务器群     |
| /29  | 248               | 8          | 8        | 6          | 极小型局域网          |
| /30  | 252               | 4          | 4        | 2          | 路由器点对点互联链路  |
+------+-------------------+------------+----------+------------+-----------------------+
```
