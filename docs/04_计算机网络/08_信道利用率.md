# 408 高频考点精讲：信道利用率

> **模块归属**：计算机网络 · 数据链路层  
> **考点层级**：微观细分核心考点（近十年考查 $\ge 3$ 次）  
> **适用对象**：408 计算机考研备考学生

## 一、 考情档案

### 1. 考查频次及命题形式

信道利用率是 408 计算机考研网络科目中兼具“理论抽象性”和“数值计算综合性”的高频考点。在历年真题中，该考点既可以以单项选择题形式考查基础参数反推、协议横向对比，也可以作为综合解答题（47题网络大题）的核心计算小问，分值分布在 2 分至 13 分之间。

- **近十年考查频次**：4 次（2016~2025 年：2023 年第 35 题、2020 年第 36 题、2018 年第 36 题、2017 年第 47 题）
- **历年总考查频次**：7 次（历史真题包含：2015 年第 35 题、2014 年第 36 题、2012 年第 36 题）
- **主要出题形式**：
  1. **定量参数计算**：已知信道带宽、传播时延、帧长，求解停等机制或流水线机制下的信道利用率。
  2. **逆向反推求解**：已知期望信道利用率，反推数据帧最小长度、发送窗口尺寸或帧序号编码位数。
  3. **协议横向对比**：在相同信道条件和帧序号位数下，对比停等协议、后退N帧（GBN）协议、选择重传（SR）协议的最大信道利用率大小关系。
  4. **综合大题联动**：结合双向数据传输、捎带确认（Piggybacking）、往返时延（RTT）及序号状态机，全流程计算实际通信利用率。

### 2. 命题特点剖析

1. **时延分量考查精细**：题目往往在“忽略确认帧传输时延”和“考虑确认帧传输时延”之间设置差异，要求考生能根据题干描述精准列出发送周期的分母项。
2. **时延带宽积概念深度融合**：流水线协议为了使信道利用率达到 $100\%$，发送窗口必须能够覆盖整个往返传播管道，这直接联系到时延带宽积（BDP）的物理实质。
3. **窗口约束和序号编码联动**：信道利用率的提升受限于发送窗口大小，而发送窗口大小又受到帧序号字段比特数 $n$ 的硬性约束（GBN 发送窗口最大为 $2^n - 1$，SR 发送窗口最大为 $2^{n-1}$）。

## 二、 具体考察内容

### 1. 核心概念及物理意义

#### （1）信道利用率（Channel Utilization）
信道利用率（记为 $U$）是指信道有数据通过的时间占信道总时间的比例。在数据链路层的可靠传输协议中，由于发送方在发送完数据后往往需要等待接收方的确认信号，发送方并非时刻都在向信道注入有效比特。因此，信道利用率可严格定义为：**在单个发送周期（发送一轮数据并收到其对应的确认所经历的总时间）内，发送方用于发送有效数据的时间占总周期的比例**。

$$U = \frac{\text{发送有效数据占用的信道时间}}{\text{发送周期总时间}}$$

若信道物理带宽为 $C$（单位：bps），在信道完全被数据填满、没有任何等待空闲时，实际传输速率达到理论最大值 $C$，此时 $U = 100\%$；若发送周期较长而发送时间较短，信道绝大部分时间处于空闲等待状态，则 $U \ll 1$。

#### （2）信道吞吐率（Channel Throughput）
信道吞吐率是指单位时间内信道无差错传输并交付到上层的有效数据比特数。它与信道物理带宽（信道容量）$C$ 以及信道利用率 $U$ 存在如下直接数学关联：

$$\text{Throughput} = U \times C$$

#### （3）时延带宽积（Bandwidth-Delay Product, BDP）
时延带宽积是指物理链路的单向传播时延 $\tau$ 和链路带宽 $C$ 的乘积（在端到端往返考查中通常延展为往返传播时延 $2\tau \times C$ 或 $\text{RTT} \times C$）：

$$\text{BDP} = \tau \times C$$

从物理图像上看，BDP 代表了充满整个单向物理链路所需要的比特数量，形象地称为“以比特为单位的链路管道容积”。若发送方在收到对端响应之前发送的数据量小于链路的管道容积，信道就不能被充分填满，信道利用率必然无法达到饱和。

### 2. 物理时延组成模型

要精确计算发送周期，必须对网络通信中的四个基础时延分量具有清晰的物理认知：

1. **发送时延（Transmission Delay / 传输时延）**：
   发送方或接收方将分组的所有比特推送到物理传输介质上所需要的时间。设分组长度为 $L$ 比特，信道传输速率（带宽）为 $C$ 比特每秒（bps），则：
   $$T_D = \frac{L_{data}}{C}, \quad T_A = \frac{L_{ack}}{C}$$
2. **传播时延（Propagation Delay）**：
   电磁波在物理传输介质（如光纤、双绞线、无线电波）中单向传播一定距离所花费的时间。设物理距离为 $D$ 米，信号在介质中的传播速度为 $v$（光纤中通常约为 $2.0 \times 10^8\text{ m/s}$，铜缆中约为 $2.3 \times 10^8\text{ m/s}$，自由空间中约为 $3.0 \times 10^8\text{ m/s}$），则单向传播时延为：
   $$\tau = \frac{D}{v}$$
3. **处理时延（Processing Delay）**：
   主机或网络节点在收到分组后，进行校验和计算、提取头部、状态机更新等处理所需的时间。在 408 考研计算中，若无特殊说明，一般忽略不计（$T_{proc} \approx 0$）。
4. **排队时延（Queuing Delay）**：
   分组在交换节点排队等待转发的时延。在单跳点对点链路考查中通常为 0。

#### 往返时延（Round-Trip Time, RTT）的边界界定
往返时延 RTT 通常指发送端从发出数据完毕起，到收到接收端发回的确认帧所耗费的往返时间。在理想双向对称链路上，若忽略处理时延，基础双向传播时延为 $2\tau$。
需要特别注意题干表述：
- 若题目明确给出“单向传播时延为 $\tau$”，则信号在链路上的往返传播时间为 $2\tau$。
- 若题目直接给出“RTT = 某个具体数值”，在标准教材及考研真题命题规范中，$\text{RTT}$ 常被视作纯粹的双向传播时延加上接收方生成确认的处理时间，即 $\text{RTT} \approx 2\tau$。但在包含确认帧发送时延计算时，需仔细核对发送周期各分量。

### 3. 停等协议（Stop-and-Wait）信道利用率数学推导

在停等协议中，发送方的发送窗口大小为 $W = 1$，接收方的接收窗口大小也为 $W_R = 1$。发送方每发送一个数据帧，就必须完全停止发送，等待对端发回确认帧（ACK）。接收方收到数据帧后回送 ACK，发送方收到 ACK 后才能发送下一个数据帧。

#### （1）时序分析及传输周期展开
一个完整的停等通信周期的时序如下：
1. $t = 0$：发送方开始向信道发送数据帧的首比特。
2. $t = T_D$：数据帧的最后一个比特发送完毕，发送方信道输出端转入空闲，发送时延结束。
3. $t = T_D + \tau$：数据帧的最后一个比特到达接收方，接收方完整接收该帧。
4. $t = T_D + \tau + T_{proc}$：接收方处理完毕，开始向信道回送确认帧 ACK。
5. $t = T_D + \tau + T_{proc} + T_A$：确认帧 ACK 的最后一个比特由接收方发送完毕。
6. $t = T_D + \tau + T_{proc} + T_A + \tau$：确认帧 ACK 的最后一个比特到达发送方。
7. 发送方接收并处理完 ACK，此时发送方可以立即发送下一个数据帧。

令 $T_{cycle}$ 表示单个完整传输周期，忽略主机微秒级的处理时延，则：
$$T_{cycle} = T_D + \tau + T_A + \tau = T_D + 2\tau + T_A$$

在此周期内，发送方真正向信道输出有效数据的时间仅为 $T_D$。

#### （2）利用率严谨公式
停等协议的信道利用率公式为：
$$U = \frac{T_D}{T_{cycle}} = \frac{T_D}{T_D + 2\tau + T_A}$$

若将往返传播时延写作 $\text{RTT} = 2\tau$，则公式可表示为：
$$U = \frac{T_D}{T_D + \text{RTT} + T_A}$$

#### （3）常见工程及考题特例简化
- **特例一：忽略确认帧发送时延（$T_A \approx 0$）**  
  在大多数非捎带确认的纯 ACK 场景中，确认帧长度很小（如几十字节），且信道带宽较高，此时 $T_A \ll T_D$ 且 $T_A \ll \tau$。题目若注明“忽略确认帧传输延时”，则：
  $$U = \frac{T_D}{T_D + 2\tau} = \frac{T_D}{T_D + \text{RTT}}$$
- **特例二：捎带确认且双向帧长对称（$T_A = T_D$）**  
  若双方处于双向持续通信状态，ACK 捎带在对端发回的数据帧中，且双方数据帧长相等，则 $T_A = T_D$，此时周期变为：
  $$T_{cycle} = T_D + 2\tau + T_D = 2T_D + 2\tau$$
  信道利用率为：
  $$U = \frac{T_D}{2T_D + 2\tau} = \frac{T_D}{2(T_D + \tau)}$$

### 4. 连续ARQ协议（流水线协议）信道利用率数学推导

为了解决停等协议因为等待 ACK 而造成的大量信道空闲问题，滑动窗口机制允许发送方在未收到确认的情况下连续发送多个帧。典型的流水线协议包括后退N帧（GBN）协议和选择重传（SR）协议。

设发送方的发送窗口尺寸为 $W$（单位：帧）。发送方可以在一个周期内连续发送至多 $W$ 个数据帧而无需等待确认。

#### （1）信道利用率通用分段函数
从发送方发出第 1 个数据帧的首比特算起，经过 $T_D + 2\tau + T_A$ 的时间，发送方开始收到对该帧的确认：
- 在这段时间内，发送方最多可以向信道推送 $W$ 个数据帧，其总发送耗时为 $W \cdot T_D$。
- **情形 A：窗口未饱和（$W \cdot T_D < T_D + 2\tau + T_A$）**  
  发送方在发完窗口内的 $W$ 个帧后，第 1 个帧的确认尚未返回，发送方必须暂停发送，信道出现闲置等待。此时发送周期仍由首帧的确认返回时间决定，总发送周期为 $T_D + 2\tau + T_A$。有效发送时间为 $W \cdot T_D$。
  信道利用率为：
  $$U = \frac{W \cdot T_D}{T_D + 2\tau + T_A}$$
- **情形 B：窗口饱和或超量（$W \cdot T_D \ge T_D + 2\tau + T_A$）**  
  发送方尚未将窗口内的 $W$ 个帧全部发完，首帧的确认就已经顺利返回。接收到确认后发送窗口立即向前滑动，发送方可以无缝继续发送新的数据帧。信道处于持续满负荷输出状态，没有出现任何空闲等待。此时信道利用率达到理论物理极限：
  $$U = 100\% = 1$$

综合上述两种情形，连续 ARQ 协议的信道利用率通用严谨公式为：
$$U = \min\left(1, \frac{W \cdot T_D}{T_D + 2\tau + T_A}\right)$$

#### （2）达到最大信道利用率（100%）的临界最小窗口尺寸
令 $\frac{W \cdot T_D}{T_D + 2\tau + T_A} \ge 1$，即可解得保证信道被完全打满的最小窗口尺寸 $W_{min}$：
$$W \ge \frac{T_D + 2\tau + T_A}{T_D} = 1 + \frac{2\tau + T_A}{T_D}$$

由于帧数量必须为正整数，故采用向上取整函数：
$$W_{min} = \left\lceil \frac{T_D + 2\tau + T_A}{T_D} \right\rceil$$

若忽略确认帧发送时延（$T_A \approx 0$），则：
$$W_{min} = \left\lceil \frac{T_D + 2\tau}{T_D} \right\rceil = \left\lceil 1 + \frac{2\tau}{T_D} \right\rceil$$

此公式反映了滑动窗口的物理本质：**发送窗口的容量必须大于或等于整个信道在往返时间内的“时延带宽积”加上首帧自身传输时间所对应的帧数容量**。

### 5. 帧序号位数约束和协议利用率极限对比

在实际通信协议中，发送窗口尺寸 $W$ 无法任意增大，它受到帧头部中“帧序号字段比特数 $n$”的强力约束。序号空间大小为 $2^n$。

#### （1）三类协议的窗口大小数学约束
1. **停等协议（Stop-and-Wait）**：
   - 发送窗口 $W_T = 1$
   - 接收窗口 $W_R = 1$
   - 帧序号空间只需满足 $W_T + W_R \le 2^n \implies 2 \le 2^n \implies n \ge 1$（通常 1 比特编码，即编号 0 和 1）。
2. **后退N帧协议（GBN）**：
   - 接收端采用单帧接收、累积确认机制，接收窗口 $W_R = 1$。
   - 若发送窗口过大，会导致旧帧确认迟滞与新帧重发序号混淆。为保证协议正确运行，发送窗口必须满足：
     $$1 \le W_T \le 2^n - 1$$
   - 对应的最大发送窗口为 $W_{GBN}^{max} = 2^n - 1$。
3. **选择重传协议（SR）**：
   - 接收端采用乱序接收并缓存的机制，通常发送窗口及接收窗口大小对称相等，即 $W_T = W_R$。
   - 为避免接收窗口的新旧重叠区间出现重叠而导致帧重复误收，必须满足：
     $$W_T + W_R \le 2^n$$
   - 当 $W_T = W_R$ 时，解得：
     $$W_T \le 2^{n-1}$$
   - 对应的最大发送窗口为 $W_{SR}^{max} = 2^{n-1}$。

#### （2）三类协议最大信道利用率大小关系严谨判定
在相同的信道物理环境（即 $T_D$、$\tau$、$T_A$ 恒定）以及相同的帧序号比特数 $n$（$n \ge 2$）条件下：
- 停等协议等价于发送窗口固定为 $W_1 = 1$。
- SR 协议（发送接收窗口对称）的最大发送窗口为 $W_3 = 2^{n-1}$。
- GBN 协议的最大发送窗口为 $W_2 = 2^n - 1$。

当 $n \ge 2$ 时，显然存在严格数量大小关系：
$$W_1 = 1 \le W_3 = 2^{n-1} < W_2 = 2^n - 1$$

例如当 $n = 3$ 时：
- $W_1 = 1$
- $W_3 = 2^{3-1} = 4$
- $W_2 = 2^3 - 1 = 7$

根据信道利用率单调递增性（上限为 1）：
$$U(W) = \min\left(1, \frac{W \cdot T_D}{T_{cycle}}\right)$$
函数在达到 1 之前关于 $W$ 严格单调递增，达到 1 之后饱和保持为 1。因此无论信道参数如何变化，必然恒有：
$$U_1 \le U_3 \le U_2$$
若窗口均未饱和，则 $U_1 < U_3 < U_2$；若信道时延极小，三者都达到 $100\%$ 饱和，则 $U_1 = U_3 = U_2 = 1$。因此统一的理论不等式关系为 $U_1 \le U_3 \le U_2$。

### 6. 重点易混淆概念对比剖析

| 概念维度 | 发送时延（传输时延）$T_D$ | 传播时延 $\tau$ |
| :--- | :--- | :--- |
| **物理本质** | 主机将数据推向信道介质的时间 | 信号在介质中穿行传播的时间 |
| **决定因素** | 数据帧大小 $L$、信道传输速率（带宽）$C$ | 介质物理距离 $D$、电磁波在介质中的传播速度 $v$ |
| **计算公式** | $T_D = \frac{L}{C}$ | $\tau = \frac{D}{v}$ |
| **技术优化途径** | 升级网卡速率、提高信道物理带宽 | 无法突破光速极限，只能缩短物理直线距离 |

---

| 概念维度 | 单向传播时延 $\tau$ | 往返时延 $\text{RTT}$ |
| :--- | :--- | :--- |
| **物理本质** | 信号沿单向链路传输一次的耗时 | 信号从发出到对端应答返回的总耗时 |
| **数学关系** | 链路对称且无处理时延时，$\text{RTT} \approx 2\tau$ | 广义包含：单向传播 + 对端生成确认 + 反向传播 |
| **考查陷阱** | 停等协议周期中传播时间需计入往返（$2\tau$） | 审题需确认题干 RTT 是否已经包含了反向传播时延 |

---

| 概念维度 | 独立确认帧（纯 ACK） | 捎带确认（Piggybacking） |
| :--- | :--- | :--- |
| **实现机制** | 接收方专程发送一个极短的控制帧（仅含头部） | 接收方将确认序号挂载在自己要发出的反向数据帧中 |
| **发送时延 $T_A$** | 极小，若题干提示忽略则设为 $T_A = 0$ | 必须按反向数据帧的完整长度计算发送时延 |
| **周期分母影响** | 分母为 $T_D + 2\tau$（或加上微小的 $T_A$） | 分母为 $T_D + 2\tau + T_{D}'$（若帧长对称则为 $2T_D + 2\tau$） |

## 三、 近十年真题精讲（2016~2025）

### 1. 2023 年 408 真题第 35 题

#### 【题目题干】
假设通过同一信道，数据链路层分别采用停等协议、GBN 协议和 SR 协议（发送窗口和接收窗口相等）传输数据，三个协议数据帧长相同，忽略确认帧长度，帧序号位数为 3 比特。若对应三个协议的发送方最大信道利用率分别是 $U_1$、$U_2$ 和 $U_3$，则 $U_1$、$U_2$ 和 $U_3$ 满足的关系是（ ）。

A. $U_1 \le U_2 \le U_3$  
B. $U_1 \le U_3 \le U_2$  
C. $U_2 \le U_3 \le U_1$  
D. $U_3 \le U_2 \le U_1$  

#### 【逐步推导解析】
1. **分析信道利用率和窗口尺寸关系**：  
   设三个协议传输的数据帧长为 $L$，信道传输速率为 $C$，数据帧发送时延为 $T_D = \frac{L}{C}$。单向传播时延为 $\tau$。忽略确认帧长度，则确认帧传输时延 $T_A \approx 0$。  
   若发送窗口大小为 $W$，则信道利用率为：
   $$U(W) = \min\left(1, \frac{W \cdot T_D}{T_D + 2\tau}\right)$$
   由于同一信道下 $T_D$ 和 $\tau$ 均相同，项 $\frac{T_D}{T_D + 2\tau}$ 恒为定值。信道利用率的上限由发送窗口的最大允许尺寸 $W_{max}$ 决定。
2. **求解三类协议的最大发送窗口尺寸**：  
   题目给出帧序号字段位数为 $n = 3$ 比特。  
   - **停等协议**：发送窗口大小恒为 $W_1 = 1$。
   - **GBN 协议**：后退N帧协议的接收窗口大小为 1，发送窗口尺寸 $W$ 需满足 $1 \le W \le 2^n - 1$。当 $n = 3$ 时，最大发送窗口为：
     $$W_2 = 2^3 - 1 = 7$$
   - **SR 协议**：选择重传协议要求发送窗口 $W_T$ 与接收窗口 $W_R$ 满足 $W_T + W_R \le 2^n$。题目明确规定发送窗口和接收窗口相等（$W_T = W_R$），因此：
     $$2 W_T \le 2^3 \implies W_T \le 2^{3-1} = 4$$
     故 SR 协议的最大发送窗口尺寸为 $W_3 = 4$。
3. **推导利用率大小排序**：  
   比较三者的最大发送窗口尺寸：
   $$W_1 = 1 < W_3 = 4 < W_2 = 7$$
   在窗口尚未饱和使得利用率达到 $100\%$ 时，信道利用率与发送窗口尺寸成正比，即 $U_1 < U_3 < U_2$。若信道传播时延非常小，使得较小窗口已能打满信道，则可能出现等于 1 的饱和相等情形。因此三者总体上必定满足：
   $$U_1 \le U_3 \le U_2$$

#### 【正确答案】
**B**

### 2. 2020 年 408 真题第 36 题

#### 【题目题干】
假设主机甲采用停-等协议向主机乙发送数据帧，数据帧长与确认帧长均为 1000 B。数据传输速率是 10 kbps，单向传播延时是 200 ms。则甲的最大信道利用率是（ ）。

A. 80%  
B. 66.7%  
C. 44.4%  
D. 40%  

#### 【逐步推导解析】
1. **参数单位标准化换算**：
   - 数据帧长 $L_{data} = 1000\text{ B} = 1000 \times 8\text{ b} = 8000\text{ 比特}$。
   - 确认帧长 $L_{ack} = 1000\text{ B} = 1000 \times 8\text{ b} = 8000\text{ 比特}$。
   - 数据传输速率 $C = 10\text{ kbps} = 10 \times 10^3\text{ bps} = 10000\text{ bps}$。
   - 单向传播延时 $\tau = 200\text{ ms} = 0.2\text{ s}$。
2. **计算各项时延分量**：
   - 数据帧发送时延：
     $$T_D = \frac{L_{data}}{C} = \frac{8000\text{ b}}{10000\text{ bps}} = 0.8\text{ s} = 800\text{ ms}$$
   - 确认帧发送时延：
     $$T_A = \frac{L_{ack}}{C} = \frac{8000\text{ b}}{10000\text{ bps}} = 0.8\text{ s} = 800\text{ ms}$$
   - 单向传播延时为 $\tau = 200\text{ ms}$，双向往返传播延时为 $2\tau = 400\text{ ms}$。
3. **计算完整传输周期**：
   在停等协议下，从发送方开始发送数据帧，到完全收到确认帧为止，总时间周期为：
   $$T_{cycle} = T_D + \tau + T_A + \tau = 800\text{ ms} + 200\text{ ms} + 800\text{ ms} + 200\text{ ms} = 2000\text{ ms} = 2.0\text{ s}$$
4. **计算信道利用率**：
   $$U = \frac{T_D}{T_{cycle}} = \frac{800\text{ ms}}{2000\text{ ms}} \times 100\% = \frac{8}{20} \times 100\% = 40\%$$

#### 【正确答案】
**D**

### 3. 2018 年 408 真题第 36 题

#### 【题目题干】
主机甲采用停-等协议向主机乙发送数据，数据传输速率是 3 kbps，单向传播延时是 200 ms，忽略确认帧的传输延时。当信道利用率等于 40% 时，数据帧的长度为（ ）。

A. 240 比特  
B. 400 比特  
C. 480 比特  
D. 800 比特  

#### 【逐步推导解析】
1. **题意提炼及变量设定**：
   - 数据传输速率 $C = 3\text{ kbps} = 3000\text{ bps}$。
   - 单向传播延时 $\tau = 200\text{ ms} = 0.2\text{ s}$。
   - 忽略确认帧的传输延时，即 $T_A = 0$。
   - 设定信道利用率 $U = 40\% = 0.4$。
   - 设数据帧长度为 $x$ 比特。
2. **列出时延方程**：
   - 数据帧的发送时延为：
     $$T_D = \frac{x}{C} = \frac{x}{3000}\text{ s}$$
   - 一个传输周期的总时间为数据帧发送时延加上往返传播时延：
     $$T_{cycle} = T_D + 2\tau + T_A = \frac{x}{3000} + 2 \times 0.2 + 0 = \frac{x}{3000} + 0.4\text{ s}$$
3. **根据利用率公式求解代数方程**：
   $$U = \frac{T_D}{T_{cycle}} = \frac{\frac{x}{3000}}{\frac{x}{3000} + 0.4} = 0.4$$
   方程两边同乘以分母：
   $$\frac{x}{3000} = 0.4 \times \left(\frac{x}{3000} + 0.4\right)$$
   $$\frac{x}{3000} = 0.4 \times \frac{x}{3000} + 0.16$$
   $$0.6 \times \frac{x}{3000} = 0.16$$
   $$\frac{x}{3000} = \frac{0.16}{0.6} = \frac{16}{60} = \frac{4}{15}\text{ s}$$
   计算数据帧长度 $x$：
   $$x = \frac{4}{15} \times 3000 = 4 \times 200 = 800\text{ 比特}$$

#### 【正确答案】
**D**

### 4. 2017 年 408 真题第 47 题

#### 【题目题干】
甲乙双方均采用后退 N 帧协议 (GBN) 进行持续的双向数据传输，且双方始终采用捎带确认，帧长均为 1000 B。$S_{x,y}$ 和 $R_{x,y}$ 分别表示甲方和乙方发送的数据帧，其中：$x$ 是发送序号；$y$ 是确认序号（表示希望接收对方的下一帧序号）；数据帧的发送序号和确认序号字段均为 3 比特。信道传输速率为 100 Mbps，$\text{RTT} = 0.96\text{ ms}$。下图给出了甲方发送数据帧和接收数据帧的两种场景，其中 $t_0$ 为初始时刻，此时甲方的发送和确认序号均为 0，$t_1$ 时刻甲方有足够多的数据待发送。

```
场景 (a):
甲方时间轴:
  t0 ----------------------------------------------------------> t1
发送: S0,0   S1,0   S2,0   S3,0          S4,1                    ??
接收:                             R0,1          R1,3    R3,3

场景 (b):
甲方时间轴:
  t0 ----------------------------------------------------------> t1
发送: S0,0   S1,0   S2,0                 S3,2   S4,2             ??
接收:                      R0,1   R1,2                  R2,2
                                               (S2,0 超时)
```

请回答下列问题。
1. 对于图 (a)，$t_0$ 时刻到 $t_1$ 时刻期间，甲方可以断定乙方已正确接收的数据帧数是多少？正确接收的是哪几个帧（请用 $S_{x,y}$ 形式给出）？
2. 对于图 (a)，从 $t_1$ 时刻起，甲方在不出现超时且未收到乙方新的数据帧之前，最多还可以发送多少个数据帧？其中第一个帧和最后一个帧分别是哪个（请用 $S_{x,y}$ 形式给出）？
3. 对于图 (b)，从 $t_1$ 时刻起，甲方在不出现新的超时且未收到乙方新的数据帧之前，需要重发多少个数据帧？重发的第一个帧是哪个（请用 $S_{x,y}$ 形式给出）？
4. 甲方可以达到的最大信道利用率是多少？

#### 【逐步推导解析】

##### 第 (1) 问解析：
- **累积确认语义**：题目指出确认序号 $y$ 表示“希望接收对方的下一帧序号”。在 GBN 协议中，确认机制是累积确认（Cumulative Acknowledgment），收到确认号 $y$ 意味着序号小于等于 $y - 1$ 的所有数据帧都已经被对端成功按序正确接收。
- **分析接收序列**：在图 (a) 中，在 $t_1$ 时刻前甲方最后收到的乙方确认帧为 $R_{3,3}$。其确认号字段为 $y = 3$。
- **确定已接收帧**：确认号为 3 说明乙方期望接收甲方的第 3 号帧，意味着甲方此前发送的 0 号、1 号、2 号帧均已被乙方完整正确接收。对照图 (a) 中甲方的发送历史，甲方发送这三个帧的具体符号形式分别为：
  $$S_{0,0}, \quad S_{1,0}, \quad S_{2,0}$$
- **结论**：已正确接收的帧数为 3 个，分别是 $S_{0,0}$、$S_{1,0}$、$S_{2,0}$。

##### 第 (2) 问解析：
- **发送窗口大小上限**：发送序号位数为 $n = 3$ 比特，序号空间为 $2^3 = 8$。在 GBN 协议中，发送窗口尺寸满足 $W \le 2^n - 1$，故甲方的最大发送窗口为 $W = 7$。
- **窗口基底位置**：由第 (1) 问可知，最后收到的确认号是 3，因此甲方当前的发送窗口下沿（基序号）滑动到了 3。发送窗口覆盖的序号范围为 $[3, (3 + 7 - 1) \bmod 8] = [3, 1]$，即包含序号：3, 4, 5, 6, 7, 0, 1（共 7 个位置）。
- **已发送而未确认的帧**：观察图 (a)，在确认号 3 确定之前，甲方已经发出的帧有 $S_{3,0}$ 和 $S_{4,1}$。这两个帧占用当前窗口中的序号 3 和序号 4。
- **可继续发送的帧数**：窗口总容量为 7，已占用 2 个位置，故最多还可以发送的帧数为：
  $$7 - 2 = 5\text{ 个}$$
- **确定帧的具体符号格式**：
  - 待发帧的发送序号依次递增，分别为 5, 6, 7, 0, 1。
  - 帧中的确认序号取甲方当前最新收到的对端数据帧序号加 1。对照官方标准答案及题干图示，甲方在此时希望接收乙方的下一帧序号为 2（接收到了乙方的 0 号和 1 号帧），因此捎带的确认号固定为 2。
  - 因此甲方发出的第一个帧为 $S_{5,2}$，最后一个帧为 $S_{1,2}$。

##### 第 (3) 问解析：
- **重发触发机制**：在图 (b) 中，在时刻 $t_1$ 前，$S_{2,0}$ 超时。GBN 协议采用回退重传策略，一旦某个已发送的帧计时器超时且未收到确认，必须重传该帧以及该帧之后已经发送的所有帧。
- **确定需要重发的帧集合**：在图 (b) 中，甲方在发送 $S_{2,0}$ 之后，又连续发送了 $S_{3,2}$ 和 $S_{4,2}$。因此未被确认的连续帧为：2号帧、3号帧、4号帧。需要重发的帧总数为：
  $$3\text{ 个}$$
- **重发第一个帧的格式**：重发的第一个帧必然是 2 号帧。在 $t_1$ 时刻，甲方已经收到了乙方的 $R_{2,2}$ 帧，这表明乙方最新发出的帧序号为 2，甲方此时期望接收的乙方下一帧序号为 $2 + 1 = 3$。因此在重发的 2 号帧中，捎带的确认号应更新为 3。故重发的第一帧符号为：
  $$S_{2,3}$$

##### 第 (4) 问信道利用率详细数学推导和计算：
- **关键物理参数提取**：
  - 数据帧长 $L = 1000\text{ B} = 8000\text{ b}$。
  - 信道带宽 $C = 100\text{ Mbps} = 100 \times 10^6\text{ bps}$。
  - 往返时延 $\text{RTT} = 0.96\text{ ms} = 0.96 \times 10^{-3}\text{ s}$。
  - 帧序号比特数 $n = 3$，GBN 发送窗口最大值 $W = 2^3 - 1 = 7$。
- **发送时延计算**：
  数据帧的发送时延为：
  $$T_D = \frac{L}{C} = \frac{8000\text{ b}}{100 \times 10^6\text{ bps}} = 8 \times 10^{-5}\text{ s} = 0.08\text{ ms}$$
  双方均持续双向传输且始终采用捎带确认，帧长均为 1000 B，因此确认帧的发送时延与数据帧完全相同：
  $$T_A = T_D = 0.08\text{ ms}$$
- **单个发送周期的总耗时展开**：
  从甲方发送某个数据帧（如 0 号帧）的首比特开始算起，到甲方收到乙方捎带确认该帧的确认帧完毕，总时间由三部分构成：
  1. 甲方发送数据帧的发送时延 $T_D$；
  2. 信号在信道中的往返时延 $\text{RTT}$（往返传播时间）；
  3. 乙方发送捎带确认帧的发送时延 $T_A$。
  
  因此，单个确认周期（即发送首帧到完全收到其 ACK 的时间）为：
  $$T_{cycle} = T_D + \text{RTT} + T_A = 0.08\text{ ms} + 0.96\text{ ms} + 0.08\text{ ms} = 1.12\text{ ms}$$
- **窗口饱和度检验**：
  在 $T_{cycle} = 1.12\text{ ms}$ 的周期时间内，甲方连续发送 $W = 7$ 个数据帧的总耗时为：
  $$W \times T_D = 7 \times 0.08\text{ ms} = 0.56\text{ ms}$$
  因为 $0.56\text{ ms} < 1.12\text{ ms}$，即发送窗口尺寸未能完全覆盖整个往返通信周期，信道存在空闲等待时间，利用率未达到 $100\%$。
- **信道利用率严格数值计算**：
  $$U = \frac{W \times T_D}{T_D + \text{RTT} + T_A} \times 100\%$$
  代入具体数据：
  $$U = \frac{7 \times 0.08\text{ ms}}{0.08\text{ ms} + 0.96\text{ ms} + 0.08\text{ ms}} = \frac{0.56\text{ ms}}{1.12\text{ ms}} = \frac{0.56}{1.12} = 0.5 = 50\%$$

#### 【正确答案】
1. 乙方已正确接收的数据帧数为 3 个，分别是 $S_{0,0}$、$S_{1,0}$、$S_{2,0}$。
2. 甲方最多还可以发送 5 个数据帧，其中第一个帧是 $S_{5,2}$，最后一个数据帧是 $S_{1,2}$。
3. 甲方需要重发 3 个数据帧，重发的第一个帧是 $S_{2,3}$。
4. 甲方可以达到的最大信道利用率是 $50\%$。

### 5. 历年经典真题点睛（2012~2015）

为了建立对信道利用率不同考察维度的全面认知，精选三道具有高度代表性的早期真题进行对照剖析：

#### （1）2015 年第 35 题：逆推帧序号比特数
- **题干要点**：卫星链路带宽 $128\text{ kbps}$，单向传播延迟 $\tau = 250\text{ ms}$，帧长 $1000\text{ B}$，不计确认帧开销。为使链路利用率不小于 $80\%$，帧序号比特数至少是？
- **推导链条**：
  1. $T_D = \frac{1000 \times 8\text{ b}}{128 \times 10^3\text{ bps}} = 62.5\text{ ms}$。
  2. 周期 $T = T_D + 2\tau = 62.5 + 2 \times 250 = 562.5\text{ ms}$。
  3. 利用率 $U = \frac{W \cdot T_D}{T} \ge 80\% \implies W \ge \frac{0.8 \times 562.5}{62.5} = 7.2$。由于窗口必须为整数，故 $W \ge 8$。
  4. 滑动窗口协议中，帧序号位数 $k$ 必须满足 $2^k \ge W + 1$（按流水线滑动窗口的一般约束，或 GBN 协议要求 $W \le 2^k - 1$），则 $2^k \ge 8 + 1 = 9 \implies k \ge 4$。至少需要 4 比特。选 B。

#### （2）2014 年第 36 题：信道利用率和吞吐率综合约束
- **题干要点**：GBN 协议，$W = 1000$，数据帧长 $1000\text{ B}$，带宽 $100\text{ Mbps}$，忽略 ACK 传输延迟，单向传播延迟 $50\text{ ms}$。求最大平均数据传输速率。
- **推导链条**：
  1. 往返传播时延 $2\tau = 100\text{ ms} = 0.1\text{ s}$。
  2. 窗口数据量为 $1000 \times 1000\text{ B} = 1\text{ MB} = 8\text{ Mb}$。
  3. 在 $0.1\text{ s}$ 内受窗口约束能发送的最大数据量速率为 $\frac{8\text{ Mb}}{0.1\text{ s}} = 80\text{ Mbps}$。
  4. 信道物理带宽为 $100\text{ Mbps}$，由于 $80\text{ Mbps} < 100\text{ Mbps}$，此时最大传输速率受限于发送窗口，故为 $80\text{ Mbps}$（信道利用率为 $80\%$）。选 C。

#### （3）2012 年第 36 题：极值条件下的最小序号位数求解
- **题干要点**：GBN 协议，带宽 $16\text{ kbps}$，单向传播时延 $270\text{ ms}$，帧长范围 $128 \sim 512\text{ B}$，确认帧与数据帧等长。为使信道利用率达到最高，序号比特数至少为？
- **推导链条**：
  1. “利用率达到最高”即要求信道利用率达到 $100\%$。要使所需窗口最大（最严苛条件），必须取最短帧长 $L = 128\text{ B}$，此时一帧发送时间最短，单位时间内需要更多帧来填满管道。
  2. $T_D = T_A = \frac{128 \times 8\text{ b}}{16 \times 10^3\text{ bps}} = 64\text{ ms}$。
  3. 周期 $T = T_D + 2\tau + T_A = 64 + 2 \times 270 + 64 = 668\text{ ms}$。
  4. 打满信道所需窗口 $W \ge \frac{668}{64} = 10.4375 \implies W_{min} = 11$。
  5. GBN 要求序号位数 $n$ 满足 $2^n - 1 \ge W_{min} = 11 \implies 2^n \ge 12 \implies n \ge 4$。选 B。

## 四、 综合解答题深度拓展

信道利用率在大题中通常与网络分层体系深度交织。通过分析历年考题，可以提炼出两大核心大题命题模型。

### 1. 双向捎带确认及非对称信道大题模型

在综合解答题中，双向传输模型是最核心的考法（如 2017 年第 47 题）。解答此类题目必须建立标准化的分析步骤：

#### 标准解题四步法
1. **第一步：画出单周期时序轴**  
   明确标出：
   - 甲方发送时延 $T_{D1} = \frac{L_1}{C_1}$
   - 前向传播时延 $\tau_1$
   - 乙方处理时延（若有）
   - 乙方发送确认（或反向数据帧）时延 $T_{D2} = \frac{L_2}{C_2}$
   - 反向传播时延 $\tau_2$
2. **第二步：求出单个确认返回周期 $T_{cycle}$**  
   $$T_{cycle} = T_{D1} + \tau_1 + T_{proc} + T_{D2} + \tau_2$$
   若信道是对称的，且题干给出了 RTT，注意核对题干中的 RTT 是否纯指传播往返（$\tau_1 + \tau_2$）。
3. **第三步：核算窗口发送数据总量及耗时**  
   发送窗口为 $W$ 时，发送方发完一个窗口耗时 $T_{send} = W \times T_{D1}$。
4. **第四步：判定饱和状态并计算利用率**  
   - 若 $W \times T_{D1} < T_{cycle}$，则利用率为 $U = \frac{W \times T_{D1}}{T_{cycle}}$。
   - 若 $W \times T_{D1} \ge T_{cycle}$，则利用率为 $U = 100\%$。

### 2. 传输层 TCP 和链路层信道利用率的跨层联动考法

在 408 考研中，传输层拥塞控制与流量控制的窗口机制与数据链路层的滑动窗口机制一脉相承。在综合大题中，常出现“根据 RTT 与链路带宽计算 TCP 慢开始与拥塞避免阶段的信道利用率”的综合题目。

#### 核心考法联动要点
1. **拥塞窗口（cwnd）与接收窗口（rwnd）的制约**：  
   TCP 发送方的实际发送窗口为 $W = \min(\text{cwnd}, \text{rwnd})$。每个 RTT 内发送方能够向网络注入的数据量即为 $W$。
2. **打满链路的临界 cwnd 计算**：  
   欲使传输层完全利用物理链路容量，必须满足：
   $$\frac{W \times \text{MSS}}{\text{RTT}} \ge C \implies W \ge \left\lceil \frac{C \times \text{RTT}}{\text{MSS}} \right\rceil$$
   此处分子 $C \times \text{RTT}$ 正是典型的**时延带宽积（BDP）**。该公式直接打通了数据链路层流水线 ARQ 和传输层 TCP 滑动窗口的底层共性。

### 3. 常见失分陷阱及答题规范

1. **速率及容量的单位换算陷阱**：
   - 在计算机网络中，描述**速率（带宽）**时采用十进制国际单位制：  
     $1\text{ kbps} = 10^3\text{ bps}$，$1\text{ Mbps} = 10^6\text{ bps}$，$1\text{ Gbps} = 10^9\text{ bps}$。
   - 描述**存储容量或分组大小**时，若给出 Byte，转为 bit 必须乘 8；但在换算前缀时需严谨审题：  
     若题目出现 $1000\text{ B}$，直接计算为 $8000\text{ b}$；若出现 $1\text{ KB}$，通常 408 真题中网络部分多视作 $1000\text{ B}$ 或 $1024\text{ B}$（题干通常会明确指定为 $1000\text{ B}$ 以简化计算，如 2017#47 与 2020#36 均明确写作 1000 B）。
2. **确认帧传输时延的遗漏或多算**：
   - 细读题干：若出现“忽略确认帧传输时延”或“短确认帧”，周期分母严禁加入 $T_A$。
   - 若出现“确认帧与数据帧等长”或“捎带确认”，周期分母必须加上对端的发送时延 $T_A$。
3. **GBN 和 SR 发送窗口边界公式混淆**：
   - 很多考生易将 GBN 的最大窗口 $2^n - 1$ 误记为 $2^n$；
   - 易将 SR 的窗口约束 $W_T + W_R \le 2^n$（对称时 $W_T \le 2^{n-1}$）与 GBN 混淆。

## 五、 考点速记清单

### 1. 核心公式速查表

| 机制类型 | 信道利用率计算公式 $U$ | 打满信道所需最小窗口 $W_{min}$ | 序号位数 $n$ 对应最大窗口 |
| :--- | :--- | :--- | :--- |
| **停等协议** | $U = \frac{T_D}{T_D + 2\tau + T_A}$ | $W = 1$（无法打满高 BDP 信道） | $n \ge 1$（常用 1 比特编码） |
| **GBN 协议** | $U = \min\left(1, \frac{W \cdot T_D}{T_D + 2\tau + T_A}\right)$ | $W_{min} = \left\lceil \frac{T_D + 2\tau + T_A}{T_D} \right\rceil$ | $W_{max} = 2^n - 1$ |
| **SR 协议** | $U = \min\left(1, \frac{W \cdot T_D}{T_D + 2\tau + T_A}\right)$ | $W_{min} = \left\lceil \frac{T_D + 2\tau + T_A}{T_D} \right\rceil$ | $W_{T}^{max} = 2^{n-1}$（发送接收对称） |

### 2. 解题核心口诀

```
发送时延看长率，长除以速推比特；
传播时延看距速，距离除以光波速。
周期分母算全套，发传收传加处理；
分子专注有效发，窗口乘上单帧时。
要想信道被打满，窗口需过时延积；
序号位数有限制，GBN减一SR半。
```

### 3. 避坑防错要点归纳

1. **审清确认帧类型**：区分“独立短 ACK（忽略时延）”及“捎带确认（计算等长时延）”。
2. **区分单向传播及往返时延**：单向传播延时为 $\tau$，停等或流水线周期必须走一个来回，传播项务必算作 $2\tau$。
3. **区分利用率和吞吐率**：吞吐率带单位（如 Mbps），信道利用率是纯百分比无量纲数。
4. **窗口及序号位数的取整方向**：
   - 求最小窗口满足利用率时，一律**向上取整（Ceil）**；
   - 序号位数 $n$ 必须满足整数幂不等式，同样向上取整。
