## 二、 具体考察内容

### 1. 传输介质层级定位及分类架构

#### 1.1 传输介质的物理层层级界定
在 OSI 参考模型和 TCP/IP 体系架构中，**传输介质不属于物理层**。传输介质位于物理层的最底层之下，通常被称为“第 0 层”。
- **物理层**：规定在传输介质上传输原始比特流的机械特性、电气特性、功能特性和规程特性，负责将高层数据转换成适合在物理介质上传输的电信号或光信号。
- **传输介质**：发送设备和接收设备之间实际传输电磁波或光波信号的物理通路。

#### 1.2 传输介质大类划分
传输介质分为两大类：
- **导向传输介质（Guided Transmission Media）**：电磁波或光波被约束在固体物理媒介中沿确定方向传播，包括双绞线、同轴电缆和光纤。
- **非导向传输介质（Unguided Transmission Media）**：电磁波在自由空间中无约束扩散传播，包括无线电波、微波、红外线及可见光。

#### 2.1 双绞线（Twisted Pair, TP）

##### 2.1.1 绞合物理原理及抑噪机制
双绞线由两根涂有绝缘保护层的对称铜导线按一定绞距（Pitch）螺旋扭绞在一起构成。
- **抑制邻近导线间串扰（Crosstalk）**：扭绞使每对线所辐射的电磁波相互抵消，显著降低对相邻线对的干扰。
- **抵抗外来电磁场共模干扰**：外来电磁场在相邻的反相绞合回路中产生的感应电动势方向相反、幅值相当，两者在闭合回路中相互抵消，大幅提高信号抗噪能力。绞距越紧密，抗干扰能力和高频传输性能越优越。

##### 2.1.2 屏蔽分类
- **非屏蔽双绞线（UTP, Unshielded Twisted Pair）**：外部仅有绝缘塑料护套，无金属屏蔽层。其造价低廉、柔韧度高、施工维护简便，是现代局域网综合布线的主流选择。
- **屏蔽双绞线（STP, Shielded Twisted Pair）**：在线对外部包裹金属箔屏蔽层（STP/FTP）或外加金属编织屏蔽网（S/FTP）。其抗电磁干扰性能极强，但成本高昂、线缆较硬、需要严格且规范的端到端接地系统，若接地不良反而会形成天线效应引入更严重的杂波。

##### 2.1.3 双绞线类别及性能指标标准体系
国际标准化组织将双绞线按其模拟带宽及数据传输能力划分为不同的“类别（Category）”：

| 类别标准 | 最高测试带宽 | 典型支持网络标准 | 最大传输距离 | 结构特征及应用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Cat 3（3类线）** | 16 MHz | 10Base-T（10 Mbps） | 100 m | 早期的局域网铜缆标准，现在多仅用于语音电话线系统 |
| **Cat 5（5类线）** | 100 MHz | 100Base-TX（100 Mbps） | 100 m | 快速以太网标准线缆，使用 2 对线芯收发 |
| **Cat 5e（超5类线）**| 100 MHz | 1000Base-T（1 Gbps） | 100 m | 优化了近端串扰（NEXT）指标，4对线全双工传输实现千兆 |
| **Cat 6（6类线）** | 250 MHz | 1000Base-T / 10GBASE-T | 100 m / 55 m | 芯线中央加入绝缘十字骨架隔离线对，短距离支持万兆 |
| **Cat 6a（超6类线）**| 500 MHz | 10GBASE-T（10 Gbps） | 100 m | 增强型外部串扰抑制能力，支持百米满跨距万兆传输 |
| **Cat 7（7类线）** | 600 MHz | 10GBASE-T | 100 m | 采用独立单对金属屏蔽加总屏蔽（S/FTP），屏蔽接地要求极严 |

##### 2.1.4 RJ-45 接头引脚定义及线序标准
双绞线网络物理接口采用 RJ-45 模块化接插件，共包含 8 个引脚针位（Pin 1 ~ Pin 8）。TIA/EIA-568 标准定义了两种接线色标线序：
- **T568A 线序**：
  - 引脚 1：白绿（TX+）
  - 引脚 2：绿（TX-）
  - 引脚 3：白橙（RX+）
  - 引脚 4：蓝
  - 引脚 5：白蓝
  - 引脚 6：橙（RX-）
  - 引脚 7：白棕
  - 引脚 8：棕
- **T568B 线序**（工程实践及考试中最常用）：
  - 引脚 1：白橙（TX+）
  - 引脚 2：橙（TX-）
  - 引脚 3：白绿（RX+）
  - 引脚 4：蓝
  - 引脚 5：白蓝
  - 引脚 6：绿（RX-）
  - 引脚 7：白棕
  - 引脚 8：棕

```text
T568A: [1:白绿] [2:绿]   [3:白橙] [4:蓝] [5:白蓝] [6:橙]   [7:白棕] [8:棕]
         |       |         |                         |
         +---+---+         +------------+------------+
             |                          |
           线对互换 (1/2 <-> 3/6)       |
             |                          |
         +---+---+         +------------+------------+
         |       |         |                         |
T568B: [1:白橙] [2:橙]   [3:白绿] [4:蓝] [5:白蓝] [6:绿]   [7:白棕] [8:棕]
```

##### 2.1.5 引脚复用及工作模式
- **10Base-T 和 100Base-TX**：只利用其中的两对共 4 根线芯。引脚 1、2 构成发送线对（TX+ / TX-），引脚 3、6 构成接收线对（RX+ / RX-）。引脚 4、5、7、8 在传输数据时不使用，处于空闲或用于 PoE 供电。
- **1000Base-T（千兆以太网）**：必须使用**全部 8 根线芯（4 个线对）**。每个线对均采用 PAM-5（5级脉冲振幅调制）编码，在每个线对上同时实现全双工双向信号传输，借助数字信号处理（DSP）消除近端回波及近端串扰。

##### 2.1.6 直通线及交叉线接线规则及 MDI/MDI-X 互联规范
- **线缆制作规则**：
  - **直通线（Straight-Through Cable）**：两端采用完全相同的线序标准（两端均为 T568B，或两端均为 T568A）。
  - **交叉线（Crossover Cable）**：一端采用 T568A 标准，另一端采用 T568B 标准。本质上是将一端的引脚 1、2 交叉连接到另一端的引脚 3、6。
- **设备端口类型属性**：
  - **MDI（Medium Dependent Interface）**：数据终端设备（DTE）的标准接口，引脚 1、2 为发送脚（TX），引脚 3、6 为接收脚（RX）。典型设备：**PC 网卡、路由器网络接口、网络打印机、服务器**。
  - **MDI-X（Medium Dependent Interface with Crossover）**：网络中间设备（DCE）的标准接口，内部已将引脚 1、2 设为接收脚（RX），引脚 3、6 设为发送脚（TX）。典型设备：**以太网交换机端口、集线器端口**。
- **线缆选型连接准则**：
  - **连接异种网络设备（MDI 接口连接 MDI-X 接口）**：使用**直通线**。
    - 示例：PC 网卡连接交换机、路由器网络接口连接交换机、PC 连接集线器。
  - **连接同种网络设备（MDI 连接 MDI，或 MDI-X 连接 MDI-X）**：使用**交叉线**。
    - 示例：PC 直接连接 PC、交换机级联交换机、集线器级联交换机。
    - **重点易错考点**：**PC 直接连接路由器**必须使用**交叉线**。因为路由器和 PC 在网络通信体系中均属于 DTE 设备，其网络接口均采用 MDI 引脚定义。如果使用直通线，两端的 TX 脚将正面对接，导致无法正常通信。
- **现代自适应翻转机制（Auto-MDIX）**：现代交换机和网卡芯片普遍内置 Auto-MDIX 功能，能够通过链路脉冲自动探测对端引脚并内部智能切换引脚收发极性，使得直通线和交叉线在工程中可透明混用。但是在 408 考研理论试卷中，仍需严格依据经典 MDI/MDI-X 规则进行判断。

#### 2.2 同轴电缆（Coaxial Cable）

##### 2.2.1 物理构造
同轴电缆由内到外由四个同心部分构成：中心内导体铜芯、绝缘介质层、外导体金属编织网屏蔽层、塑料保护外护套。这种共轴心设计赋予了同轴电缆出色的抗外来高频电磁干扰能力。

##### 2.2.2 阻抗分类及应用场景
- **50 $\Omega$ 基带同轴电缆**：特性阻抗为 50 欧姆，专门用于传输数字基带方波信号。早期 IEEE 802.3 规范采用：
  - **10Base5（粗缆以太网）**：电缆粗硬，最大单段传输距离为 500 米，通过收发器穿刺接入（Transceiver）。
  - **10Base2（细缆以太网）**：使用 RG-58 细电缆和 BNC T型头接入，最大单段传输距离为 185 米。
- **75 $\Omega$ 宽带同轴电缆**：特性阻抗为 75 欧姆，用于传输经过频分复用（FDM）的宽带模拟射频信号。广泛应用于有线电视网（CATV）以及基于 HFC（光纤同轴混合网）的 Cable Modem 宽带接入系统。

#### 2.3 光纤（Optical Fiber）

##### 2.3.1 光全反射物理机制
光纤通信建立在几何光学全反射定律的基础之上。
- 光纤构造包含两层玻璃介质：中心的高折射率纤芯（Core，折射率 $n_1$）和外围的低折射率包层（Cladding，折射率 $n_2$），且必须满足：
  $$n_1 > n_2$$
- 当光纤端面注入的光线由光密介质（纤芯）射向光疏介质（包层）时，若入射角 $\theta$ 大于全反射临界角 $\theta_c$，光线将不再透射折射入包层，而是发生全反射并沿纤芯呈锯齿状向前无损反射传播：
  $$\theta_c = \arcsin\left(\frac{n_2}{n_1}\right)$$

##### 2.3.2 单模光纤及多模光纤多维参数深度剖析

```text
多模光纤 (MMF): 纤芯粗 (50~62.5 μm)，多路光线多角度全反射，模间色散严重
      ---------------------------------------------------------
包层  ---------------------------------------------------------
纤芯    \  /\  /\  / 光路 A
        --\--\/--\/-------------------------------------------- (轴向光线: 光路 B)
包层  ---------------------------------------------------------
      ---------------------------------------------------------

单模光纤 (SMF): 纤芯细 (8~10 μm)，单一直线轴向无反射传播，无模间色散
      ---------------------------------------------------------
包层  ---------------------------------------------------------
纤芯  =========================================================> (光线沿轴心直线传播)
包层  ---------------------------------------------------------
      ---------------------------------------------------------
```

光纤按光在纤芯中的传输模式可分为**单模光纤（Single Mode Fiber, SMF）**和**多模光纤（Multi Mode Fiber, MMF）**。二者在几何尺寸、物理学原理及工程性能的系统对比如下：

| 对比维度 | 单模光纤（SMF） | 多模光纤（MMF） |
| :--- | :--- | :--- |
| **纤芯直径** | 极细，典型值为 **$8 \sim 10\ \mu\text{m}$**（接近光波长量级） | 较粗，典型值为 **$50\ \mu\text{m}$** 或 **$62.5\ \mu\text{m}$** |
| **包层外径** | 统一标准为 $125\ \mu\text{m}$ | 统一标准为 $125\ \mu\text{m}$ |
| **光源类型** | **半导体激光器（LD, Laser Diode）**，谱线极窄、定向性极高 | **发光二极管（LED）** 或垂直腔面发射激光器（VCSEL） |
| **工作波长** | $1310\ \text{nm}$（色散极小窗口）和 $1550\ \text{nm}$（损耗极低窗口） | $850\ \text{nm}$ 或 $1300\ \text{nm}$ |
| **光传输模式** | 只有基模（$HE_{11}$）一种模式沿轴线无反射直线前进 | 存在几十到上百种不同反射角度的传播模式在纤芯中反射前进 |
| **色散现象** | **完全不存在模间色散**，仅存在极微弱的波长色散（材料/波导色散） | **模间色散极严重**（不同光路传播路径长度不同导致到达时刻展宽） |
| **信号衰减** | 极低（在 $1550\ \text{nm}$ 窗口衰减约为 $0.2\ \text{dB/km}$） | 较高（在 $850\ \text{nm}$ 窗口衰减约为 $2 \sim 3\ \text{dB/km}$） |
| **传输距离** | **极远（数公里至数十公里甚至上百公里）**，用于骨干网及城域网 | **较短（通常在几百米到 2 公里以内）**，多用于局域网内部及机房连接 |
| **造价成本** | 光缆本身价格低廉，但**激光光收发模块成本极高** | 多模光收发模块使用 LED，**系统整体造价低廉** |

##### 2.3.3 光纤色散的物理本质剖析
色散（Dispersion）是指光脉冲在光纤中传输时，由于不同速度成分的传播时延不同，导致信号脉冲随传输距离增加而沿时间轴展宽（脉冲平展）。脉冲过度展宽会导致严重的码间串扰（ISI），从而限制通信速率和传输距离。
- **模间色散（Modal Dispersion）**：**多模光纤所特有**。纤芯中不同传播模式的光线沿不同角度全反射，光程长短不同，导致各模式到达纤芯末端的时间先后不一。
- **材料色散及波导色散（色度色散 Chromatic Dispersion）**：光源发出的光并非严格单色，不同波长（频率）的光在介质中具有不同的折射率，因而传播速度存在微弱差异。单模光纤消除了模间色散，其传输距离主要受微弱的色度色散和衰减制约。

### 3. IEEE 802.3 物理层规范命名规则全景表

### 4. 物理介质时延推导及以太网争用期数学模型

#### 4.1 电磁波在物理介质中的传播速度常数
电磁波在不同物理介质中的传播速度取决于介质的介电常数及折射率：
- **真空中的光速**：$c = 3.0 \times 10^8\ \text{m/s}$。
- **铜缆（双绞线、同轴电缆）中的电磁波速度**：$v_{\text{copper}} \approx 2.0 \times 10^8\ \text{m/s} = 200\ \text{m/\mu s}$（约为光速的 2/3）。
- **光纤中的光波速度**：因二氧化硅玻璃纤芯折射率 $n \approx 1.5$，根据 $v = \frac{c}{n}$，光波传播速度同样为：
  $$v_{\text{fiber}} = \frac{3.0 \times 10^8\ \text{m/s}}{1.5} = 2.0 \times 10^8\ \text{m/s} = 200\ \text{m/\mu s}$$
- **考研计算标准约定**：若题干未给出具体速度数值，一般默认取 $2.0 \times 10^8\ \text{m/s}$；若题干明确给出，以题干输入值为准。

#### 4.2 传播时延及发送时延（传输时延）计算公式
- **传播时延（Propagation Delay）**：电磁波在介质物理长度 $D$ 上走过所需耗费的时间：
  $$t_{\text{prop}} = \frac{D}{v}$$
- **发送时延（Transmission Delay / Packet Delay）**：网络设备将数据帧的全部比特推向传输介质所需的时间：
  $$t_{\text{trans}} = \frac{L}{R}$$
  其中 $L$ 为数据帧长度（单位：bit），$R$ 为链路数据传输速率（单位：bps）。

#### 4.3 介质限制下 CSMA/CD 争用期及最小帧长推导
以太网在半双工模式下运行 CSMA/CD（载波监听多路访问/碰撞检测）协议。为保证发送站点在帧发送完毕之前必然能够检测到信道上因冲突产生的碰撞信号，**帧的发送时延必须大于等于端到端往返传播时延（RTT）加上信号通过中间转发设备产生的总附加时延**：
$$t_{\text{trans}} \ge 2 \times t_{\text{prop}} + t_{\text{devices}} = \text{RTT}$$
代入参数展开：
$$\frac{L_{\min}}{R} \ge \frac{2 D_{\max}}{v} + \sum t_{\text{device}}$$
由此可导出以太网介质覆盖的最大物理跨距 $D_{\max}$：
$$D_{\max} \le \frac{v}{2} \times \left( \frac{L_{\min}}{R} - \sum t_{\text{device}} \right)$$

- **以太网最小帧长来源**：
  在 10Base-T（$R = 10\ \text{Mbps}$）标准中，根据设计规范，争用期（Slot Time）设定为 $2\tau = 51.2\ \mu\text{s}$。因此，以太网最小有效帧长为：
  $$L_{\min} = R \times 2\tau = 10\ \text{Mbps} \times 51.2\ \mu\text{s} = 512\ \text{bit} = 64\ \text{Byte}$$
- 任何小于 64 字节的以太网帧均为无效的“冲突残片（Runt Frame）”，接收端物理层将直接丢弃。

#### 4.4 截断二进制指数退避算法（Truncated Binary Exponential Backoff）
当网卡检测到冲突碰撞后，停止发送并发送 32 或 48 比特的强化冲突干扰信号（Jamming Signal），随后启动截断二进制指数退避算法计算等待重发的时间间隔：
1. **确定基本退避时间单位**：以争用期 $2\tau$（Slot Time）为基本时间片单位（对于 10Base-T，争用时间片为 $51.2\ \mu\text{s}$；对于 100Base-T，为 $5.12\ \mu\text{s}$）。
2. **确定退避参数 $k$**：设已发生连续冲突的次数为 $n$（第 $n$ 次重传），则参数 $k$ 取值为：
   $$k = \min(n, 10)$$
3. **随机选择等待时隙数 $r$**：从离散均匀分布集合中等概率随机抽取一个整数 $r$：
   $$r \in \{0, 1, 2, \dots, 2^k - 1\}$$
4. **计算退避等待时间**：
   $$T_{\text{backoff}} = r \times 2\tau$$
5. **重传上限及异常终止**：
   - 当冲突次数 $n \le 10$ 时，退避空间按 $2^n$ 呈指数倍级扩大。
   - 当冲突次数 $10 < n \le 16$ 时，退避参数被强行截断冻结在 $k = 10$，此时 $r$ 的取值范围固定在 $[0, 1023]$。
   - 若连续发生冲突次数达到 16 次（$n = 16$），网卡判定信道拥塞极其严重，立即停止重传并向上层协议栈报错，丢弃该帧。

### 5. 重点易混淆概念深度辨析

#### 辨析一：传输介质及物理层接口标准的层级界线
- **错误理解**：认为双绞线、光纤就是物理层的一部分。
- **正确理解**：物理层是体系结构的第一层，它规定了在各种传输介质之上如何传输原始比特流的四个接口特性（机械、电气、功能、规程）。而双绞线、同轴电缆、光纤、无线电波是物理通路，位于物理层之下（第 0 层）。物理层将比特映射为电平或光脉冲，依靠传输介质进行物理传播。

#### 辨析二：信号传输速率（比特率）及电磁波传播速度（波速）
- **错误理解**：将网速（如百兆 100 Mbps、千兆 1 Gbps）误认为是信号在导线中传播的速度变快了。
- **正确理解**：
  - **传播速度（$v$）**：电磁波在传输介质中的物理行进速度，只取决于介质的物理材质（铜缆中约 $2.0 \times 10^8\ \text{m/s}$，光纤中约 $2.0 \times 10^8\ \text{m/s}$）。网络从 10Base-T 升级到 1000Base-T，电磁波在双绞线里的传播速度分毫未变。
  - **传输速率（$R$）**：网卡发送器向信道注入比特的时钟频率。速率提升意味着单位时间内向信道发射的比特数量增多，每个比特在时间轴上的持续脉宽变窄，在空间上排布的比特物理长度变短。

#### 辨析三：多模光纤模间色散及单模光纤无模间色散的物理机制
- **错误理解**：认为单模光纤没有色散，所以能够无限远传输。
- **正确理解**：多模光纤纤芯较粗（$50\ \mu\text{m}$），光线在纤芯内有多条全反射路径，由于路径长度差异导致不同模式光到达时间先后不一，产生极其严重的**模间色散**；而单模光纤纤芯极细（$8 \sim 10\ \mu\text{m}$），仅容许一种沿轴线传播的基模通过，因此**完全不存在模间色散**。然而，由于激光光源并非绝对单一频率，单模光纤中仍然存在微弱的**材料色散和波导色散（色度色散）**，再叠加介质衰减共同作用，使得单模光纤虽能长达数十公里，但无法实现真正无限距离传输。

#### 辨析四：直通线及交叉线引脚翻转的本质逻辑
- **错误理解**：死记“同种设备用交叉线，异种设备用直通线”，在遇到 PC 连接路由器时误判为异种设备而选用直通线。
- **正确理解**：引脚连接的本质要求是：**一端的发送端口（TX+ / TX-）必须物理连通到对端的接收端口（RX+ / RX-）**。
  - PC、路由器、网络打印机、服务器等设备内部硬件均属终端设备（DTE），物理引脚 1、2 是 TX，3、6 是 RX；
  - 交换机和集线器内部已经做了端口交叉（MDI-X），引脚 1、2 是 RX，3、6 是 TX。
  - 因此，PC 连接交换机使用直通线（TX 直接连入 RX）；而 PC 连接路由器是 DTE 直连 DTE，两端引脚 1、2 均为 TX，必须借助交叉线在外部线缆中完成 1/2 及 3/6 的位置倒置。

### 2025 年全国统考 408 真题第 35 题

#### 题干
现有一 10BaseT 以太网，甲乙处于同一个冲突域，连续发生 11 次冲突，甲再次发送的最大时间间隔为（ ）。
A. 0.512 ms  
B. 0.5632 ms  
C. 52.3776 ms  
D. 104.8064 ms  

#### 逐步深度推导解析
1. **提取介质参数及基本时隙（Slot Time）**：
   - 题目给定网络为 **10BaseT** 以太网。根据 IEEE 802.3 规范，10BaseT 的数据传输速率为 $R = 10\ \text{Mbps}$，最小帧长为 64 字节（512 比特）。
   - 其争用期（基本退避时隙时间片）为：
     $$\tau = \frac{512\ \text{bit}}{10\ \text{Mbps}} = \frac{512\ \text{bit}}{10 \times 10^6\ \text{bps}} = 51.2\ \mu\text{s} = 0.0512\ \text{ms}$$
2. **分析截断二进制指数退避算法机制**：
   - 冲突次数记为 $n$。题目明确指出“连续发生 11 次冲突”，即当前准备进行第 12 次重传尝试，连续冲突计数 $n = 11$。
   - 退避参数计算公式为：
     $$k = \min(n, 10)$$
     由于 $n = 11 > 10$，因此退避参数被强行截断取上限值：
     $$k = 10$$
3. **确定时隙系数 $r$ 的取值范围及最大值**：
   - 网卡随机选取的整数倍数 $r$ 来自集合 $\{0, 1, 2, \dots, 2^k - 1\}$。
   - 代入 $k = 10$：
     $$r \in \{0, 1, 2, \dots, 2^{10} - 1\} = \{0, 1, 2, \dots, 1023\}$$
   - 甲再次发送的最大等待时隙数为集合上限：
     $$r_{\max} = 1023$$
4. **计算最大时间间隔**：
   - 最大退避等待时间间隔为：
     $$T_{\max} = r_{\max} \times \tau = 1023 \times 51.2\ \mu\text{s} = 52377.6\ \mu\text{s}$$
   - 将微秒转换为毫秒（$\text{ms}$）：
     $$T_{\max} = \frac{52377.6}{1000}\ \text{ms} = 52.3776\ \text{ms}$$
5. **甄别迷惑选项**：
   - 选项 A（0.512 ms）：对应 $10 \times 51.2\ \mu\text{s}$，为混淆退避次数的低级干扰项。
   - 选项 B（0.5632 ms）：对应 $11 \times 51.2\ \mu\text{s}$，误以为退避时间直接同连续冲突次数相乘。
   - 选项 D（104.8064 ms）：对应若未执行截断而直接计算 $k = 11$，即 $(2^{11} - 1) \times 51.2\ \mu\text{s} = 2047 \times 51.2\ \mu\text{s} = 104.8064\ \text{ms}$。这是命题人特意针对未掌握“$k \le 10$ 截断规则”的考生设置的典型陷阱。

#### 【正确答案】
**C**

### 2023 年全国统考 408 真题第 36 题

#### 题干
已知 10BaseT 以太网的争用时间片为 51.2 $\mu\text{s}$。若网卡在发送某帧时发生了连续 4 次冲突，则基于二进制指数退避算法确定的再次尝试重发该帧前等待的最长时间是（ ）。
A. 51.2 $\mu\text{s}$  
B. 204.8 $\mu\text{s}$  
C. 768 $\mu\text{s}$  
D. 819.2 $\mu\text{s}$  

#### 逐步深度推导解析
1. **明确输入参数**：
   - 10BaseT 争用时间片（时隙）$\tau = 51.2\ \mu\text{s}$。
   - 连续发生冲突次数 $n = 4$。
2. **应用二进制指数退避算法计算退避区间**：
   - 退避阶数 $k = \min(n, 10) = \min(4, 10) = 4$。
   - 随机选取的整数倍数 $r$ 的离散分布范围为：
     $$r \in [0, 2^k - 1] = [0, 2^4 - 1] = [0, 16 - 1] = [0, 15]$$
3. **求取等待最长时间**：
   - 题目求解“等待的最长时间”，即取 $r$ 的最大可能值 $r_{\max} = 15$。
   - 最长等待时间为：
     $$T_{\max} = 15 \times \tau = 15 \times 51.2\ \mu\text{s} = 768\ \mu\text{s}$$
4. **排除干扰项分析**：
   - 选项 A（$51.2\ \mu\text{s}$）：误取 $r = 1$。
   - 选项 B（$204.8\ \mu\text{s}$）：误用冲突次数直接乘争用时间片（$4 \times 51.2 = 204.8\ \mu\text{s}$）。
   - 选项 D（$819.2\ \mu\text{s}$）：误将最大上限记为 $2^k$（$16 \times 51.2\ \mu\text{s} = 819.2\ \mu\text{s}$），遗漏了区间公式中的减 1 修正（即取了 $2^k$ 而非 $2^k - 1$）。

#### 【正确答案】
**C**

#### 逐步深度推导解析

##### 第 1 小问：设备选型判定
- **分析依据**：
  - 题目指出：H1 与 H2 属于同一个广播域，但不属于同一个冲突域；H2 和 H3 属于同一个冲突域。
  - **网络设备的隔离特性判定法则**：
    - 集线器（Hub）：物理层设备，既不能隔离广播域，也不能隔离冲突域（所有端口处于同一冲突域、同一广播域）。
    - 交换机（Switch）：数据链路层设备，每个端口独占一个冲突域，即**能够隔离冲突域**；但不划分 VLAN 时**不能隔离广播域**。
    - 路由器（Router）：网络层设备，既能隔离冲突域，也能隔离广播域。
  - **推导过程**：
    - H2 和 H3 处于同一个冲突域，说明连接 H2、H3 的**设备 2** 无法隔离冲突域，因此设备 2 必须是**物理层设备——100BaseT 集线器（Hub）**。
    - H1 和 H2 属于同一广播域但不同冲突域，说明在 H1 和设备 2 之间存在冲突域隔离设备，因此**设备 1** 必须是**数据链路层设备——100BaseT 以太网交换机（Switch）**。

##### 第 2 小问：传输介质传播时延及 CSMA/CD 极限距离推导（核心考点）
- **物理机制剖析**：
  - H2 和 H3 通过 100BaseT 集线器相连，集线器工作在物理层共享总线模式下，各主机采用 CSMA/CD 协议进行半双工争用通信。
  - 为确保当信道上发生冲突时，发送站点在完成整帧发送之前能够检测到碰撞，必须满足“数据帧发送时延 $\ge$ 信号双向端到端往返时延（争用期）”：
    $$t_{\text{trans}} \ge \text{RTT}$$
- **参数代入及公式建立**：
  - **链路速率**：标准为 100BaseT，故传输速率 $R = 100\ \text{Mbps} = 10^8\ \text{bps}$。
  - **最小帧长发送时延**：
    $$t_{\text{trans}} = \frac{L_{\min}}{R} = \frac{64 \times 8\ \text{bit}}{100 \times 10^6\ \text{bps}} = \frac{512\ \text{bit}}{10^8\ \text{bps}} = 5.12 \times 10^{-6}\ \text{s} = 5.12\ \mu\text{s}$$
  - **端到端往返时延 RTT 构成**：
    设 H2 到 H3 的物理线缆总长度为 $D$。信号单向传播包含两部分：物理线缆传播时延 $\frac{D}{v}$ 以及通过设备 2（集线器内部放大整形转发）产生的单向硬件时延 $t_{\text{hub}} = 1.51\ \mu\text{s}$。
    因此，信号在 H2 和 H3 之间的最坏双向往返时延为：
    $$\text{RTT} = 2 \times \left( \frac{D}{v} + t_{\text{hub}} \right)$$
- **代入求解极值**：
  $$5.12\ \mu\text{s} \ge 2 \times \left( \frac{D}{2 \times 10^8\ \text{m/s}} + 1.51\ \mu\text{s} \right)$$
  两边同时除以 2：
  $$2.56\ \mu\text{s} \ge \frac{D}{2 \times 10^8\ \text{m/s}} + 1.51\ \mu\text{s}$$
  移项计算纯介质单向传播时延：
  $$\frac{D}{2 \times 10^8\ \text{m/s}} \le 2.56\ \mu\text{s} - 1.51\ \mu\text{s} = 1.05\ \mu\text{s} = 1.05 \times 10^{-6}\ \text{s}$$
  解得线缆距离 $D$ 的最大值：
  $$D \le 1.05 \times 10^{-6}\ \text{s} \times (2 \times 10^8\ \text{m/s}) = 210\ \text{m}$$
  因此，H2 和 H3 之间允许相距的最远距离为 **210 米**。

##### 第 3 小问：DHCP 报文及二层广播处理
- H4 最初发送的报文 M 为 **DHCP 发现报文（DHCP Discover）**。
- DHCP Discover 报文封装在 UDP 数据报中，通过广播形式发送（目的 IP 为 255.255.255.255，目的 MAC 为 FF-FF-FF-FF-FF-FF）。
- 因为以太网交换机 S 对广播帧执行全端口泛洪（Flooding），所以路由器 E0 接口在同一个广播域内，**能够收到**封装 M 的以太网帧。
- 交换机 S 转发该广播帧时不会改变其源及目的 MAC 地址，因此转发给 DHCP 服务器的以太网帧的目的 MAC 地址依然为全 1 广播地址：**FF-FF-FF-FF-FF-FF**。

##### 第 4 小问：802.11 帧地址字段规则推导
- 在 IEEE 802.11 无线局域网体系中，AP 连接有线骨干网时（From DS = 1, To DS = 0，即帧由 AP 发送至无线工作站 H5）：
  - **地址 1（RA / DA）**：接收端/目的端 MAC 地址，即 H5 的 MAC 地址（`00-11-11-11-11-E1`）。
  - **地址 2（TA / BSSID）**：发送端无线接口/基本服务集标识，即 AP 的 MAC 地址（`00-11-11-11-11-C1`）。
  - **地址 3（SA）**：源主机 MAC 地址，即产生该数据的发送源 H4 的 MAC 地址（`00-11-11-11-11-D1`）。

#### 【参考答案】
1. 设备 1 选用 **100BaseT 以太网交换机**；设备 2 选用 **100BaseT 集线器**。
2. H2 和 H3 之间可以相距的最远距离是 **210 m**。
3. 报文 M 是 **DHCP 发现报文（DHCP Discover）**；路由器 E0 接口**能**收到封装 M 的以太网帧；S 向 DHCP 服务器转发该帧的目的 MAC 地址是 **FF-FF-FF-FF-FF-FF**。
4. 地址 1 为 **00-11-11-11-11-E1**，地址 2 为 **00-11-11-11-11-C1**，地址 3 为 **00-11-11-11-11-D1**。

### 2019 年全国统考 408 真题第 34 题

#### 题干
100BaseT 快速以太网使用的导向传输介质是（ ）。
A. 双绞线  
B. 单模光纤  
C. 多模光纤  
D. 同轴电缆  

#### 逐步深度推导解析
1. **IEEE 802.3 物理层术语词根解构**：
   - 快速以太网标准代号为 **100BaseT**。
   - 前缀数字 **100**：代表数据传输速率为 $100\ \text{Mbps}$。
   - 词干 **Base**：代表采用基带传输模式（Baseband Transmission），不使用高频载波调制。
   - 后缀字母 **T**：是英文 **Twisted Pair（双绞线）** 的首字母缩写。
2. **同类介质标识横向对比**：
   - 双绞线以太网标识：10Base-T、100Base-TX、1000Base-T（均带有字母 **T**）。
   - 光纤以太网标识：100Base-FX、1000Base-SX、1000Base-LX（带有字母 **F**、**S**、**L** 代表 Fiber / Short-wavelength / Long-wavelength）。
   - 同轴电缆以太网标识：10Base5（粗缆）、10Base2（细缆）。
3. 故 100BaseT 所使用的导向物理传输介质必然为双绞线（具体多为 5 类或超 5 类非屏蔽双绞线 UTP）。

#### 【正确答案】
**A**

### 【历史经典真题补充精讲】2013 年全国统考 408 真题第 34 题

#### 题干
若下图为 10BaseT 网卡接收到的信号波形，则该网卡收到的比特串是（ ）。

```text
电平示意波形图（每个码元周期居中发生电平跃变）：
周期:  |   1   |   2   |   3   |   4   |   5   |   6   |   7   |   8   |
波形:  | 低-高 | 低-高 | 高-低 | 高-低 | 低-高 | 高-低 | 高-低 | 低-高 |
```

A. 0011 0110  
B. 1010 1101  
C. 0101 0010  
D. 1100 0101  

#### 逐步深度推导解析
1. **物理层介质及编码协议对应**：
   - 题目给定为 **10BaseT** 网卡。根据 IEEE 802.3 规范，传统 10BaseT 以太网物理层规定采用**曼彻斯特编码（Manchester Encoding）**。
2. **曼彻斯特编码规则辨析**：
   - 曼彻斯特编码的核心特征是：在每一个码元周期的**正中心位置**都必须发生一次确定性的电平跳变。该电平跳变兼具时钟同步提取及数据位承载双重功能。
   - 编码极性有两种学术定义规范：
     - **IEEE 802.3 标准规范**：由**高电平跳变到低电平**表示比特 **0**；由**低电平跳变到高电平**表示比特 **1**。
     - **传统/教材逆规范**：由**低电平跳变到高电平**表示比特 **0**；由**高电平跳变到低电平**表示比特 **1**。
3. **对照选项验证波形**：
   - 观察题目波形序列：
     - 周期 1：低 $\to$ 高
     - 周期 2：低 $\to$ 高
     - 周期 3：高 $\to$ 低
     - 周期 4：高 $\to$ 低
     - 周期 5：低 $\to$ 高
     - 周期 6：高 $\to$ 低
     - 周期 7：高 $\to$ 低
     - 周期 8：低 $\to$ 高
   - 若按 **逆向约定**（低到高为 0，高到低为 1）：
     - 对应比特串为：`0 0 1 1 0 1 1 0`。此结果同选项 A 完全吻合。
   - 若按 **IEEE 802.3 标准**（低到高为 1，高到低为 0）：
     - 对应比特串为：`1 1 0 0 1 0 0 1`。观察选项 B、C、D，均无此项。
   - 由此可知，出题人采用了低到高代表 0、高到低代表 1 的映射约定，答案唯一确定为 A。

#### 【正确答案】
**A**

## 四、 综合解答题深度拓展（大题考法联动）

在 408 综合大题（尤其是第 47 题）中，传输介质常作为物理层基石，同数据链路层介质访问控制、网络拓扑搭建、跨层往返时延（RTT）及端到端信道利用率形成深度联动。其考查模式可系统提炼为以下三大命题模型：

### 模型一：介质传播时延 + 中间设备延时 + CSMA/CD 碰撞域极限推导
此类大题考查在给定物理传输介质类型、拓扑结构和中间级联设备下的极限物理距离反算（如 2022#47 原型及其衍生变式）：
- **标准推导公式**：
  $$t_{\text{trans}} = \frac{L_{\min}}{R} \ge \text{RTT} = 2 \times \sum_{i=1}^{k} \frac{D_i}{v_i} + 2 \times \sum_{j=1}^{m} t_{\text{hub}_j}$$
- **通用解题四步法**：
  1. **识别冲突域边界**：根据集线器不隔离冲突域、交换机隔离冲突域的特性，划定产生冲突竞争的物理总线网段范围，滤除交换机对侧无关的主机和链路。
  2. **提取最小帧长及速率**：从协议标准（如 100BaseT 对应 $100\ \text{Mbps}$ 和 $64\ \text{B}$）计算发送该最小帧所需的基准时间 $t_{\text{trans}}$。
  3. **核算双向往返时延**：严格注意信号是**往返双向**传播，介质单向时延 $\frac{D}{v}$ 和中间集线器的硬件转发时延 $t_{\text{device}}$ 都必须**乘以 2**。
  4. **单位统一度量衡**：注意将微秒（$\mu\text{s}$）化为秒（$\text{s}$）、字节（Byte）化为比特（bit）进行规范换算，避免因单位错漏丢分。

### 模型二：传输介质选型 + 光纤衰减预算 + 长途干线时延跨层计算
在城域网或跨园区互联背景的大题中，常考查双绞线及光纤的混合设计选型：
- **距离约束及介质匹配**：
  - 楼宇内配线间到桌面主机：距离 $\le 100\ \text{m}$，强制选用 **Cat 5e/Cat 6 UTP 双绞线**。
  - 园区楼栋间互联：距离 $500\ \text{m} \sim 2\ \text{km}$，选用 **多模光纤（1000Base-SX）**。
  - 跨城域/长途数据中心骨干：距离 $> 5\ \text{km}$，选用 **单模光纤（1000Base-LX / 1000Base-ZX）**。
- **端到端 RTT 构成及信道利用率联动**：
  在停等协议或滑动窗口协议（如 GBN、SR、TCP）的利用率大题中：
  $$\text{RTT} = 2 \times \frac{D_{\text{fiber}}}{v_{\text{fiber}}} + t_{\text{switch\_process}}$$
  信道利用率计算公式：
  $$U = \frac{N \times t_{\text{trans}}}{t_{\text{trans}} + \text{RTT} + t_{\text{ack\_trans}}}$$
  此处物理介质长度 $D$ 直接决定了 $\text{RTT}$，进而成为推导流水线协议最佳窗口大小（$W_{\text{optimal}} \approx 1 + \frac{\text{RTT}}{t_{\text{trans}}} = 1 + 2a$）的决定性物理因子。

### 模型三：布线引脚故障诊断及抓包通信异常分析
在大题的故障诊断情境中，题目给出具体设备的互联拓扑及网线类型：
- **典型考法陷阱**：
  - 题目给出两台路由器通过直通网线直接背靠背相连，或者两台普通 PC 之间使用直通双绞线对联，问“为何物理层 Link 灯不亮或网络层无法 ping 通？”
  - **采分答案要点**：PC 和路由器均属 DTE 设备，其网卡接口为 MDI 引脚规范（1、2 脚发送，3、6 脚接收）。若采用直通线，两端发送脚直接对接，导致接收端无信号。必须更换为**交叉双绞线（一端 T568A，另一端 T568B）**以将一端的 TX 交叉连入对端的 RX；或在支持 **Auto-MDIX** 的端口上开启自适应翻转功能。

### 3. 经典避坑防错要点

1. **层级归属避坑**：传输介质不是物理层本身，传输介质在物理层之下（第 0 层）。物理层规定的是介质上的接口特性。
2. **千兆线芯利用避坑**：百兆以太网（100Base-TX）只用 1、2、3、6 四根线芯（两对线）；**千兆以太网（1000Base-T）强制使用全部 8 根线芯（四对线）**同时进行全双工收发。
3. **光纤色散避坑**：单模光纤**绝对没有模间色散**，但并非完全没有色散（仍有极弱的材料色散及波导色散）。多模光纤传输距离受限的首要物理瓶颈正是模间色散。
4. **指数退避取值避坑**：
   - 连续发生 11 次冲突，第 12 次重传时，$k = \min(11, 10) = 10$，取值上限是 $2^{10} - 1 = 1023$，绝不是 $2^{11} - 1$。
   - 最大时隙数是 $2^k - 1$，切勿漏掉减 1 误写成 $2^k$。
5. **CSMA/CD 往返系数避坑**：在根据最小帧长计算极限跨距时，总时延必须是**双向往返时延（RTT）**。无论是介质单向走时 $\frac{D}{v}$ 还是经过集线器的延迟 $t_{\text{device}}$，进入计算时均须**乘以 2**。
6. **设备互联线序避坑**：
   - 同种设备（DTE-DTE，DCE-DCE）用交叉线；异种设备（DTE-DCE）用直通线。
   - 特别牢记：**PC 和路由器相连必须使用交叉线**，因为二者在网络工程中均定义为 DTE。
