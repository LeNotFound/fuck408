### 1. 字长体系的层级解构与硬件对应

在计算机体系结构中，“字长”（Word Length）表征计算机一次能够处理、传送或存储的二进制代码位数。必须从底层硬件物理通路上严格界定以下三类字长：

```text
               +-------------------------------------------------+
               |                   CPU 内部                      |
               |                                                 |
               |   +-------------+          +----------------+   |
               |   | 通用寄存器  |          | 算术逻辑单元   |   |
               |   | (GPR, n位)  |<========>| (ALU, n位)     |   |
               |   +-------------+          +----------------+   |
               |         ^                         ^             |
               |         |=== 机器字长（定点数据通路宽 n 位） =====|             |
               |                                                 |
               |   +-------------+          +----------------+   |
               |   | 指令寄存器  |          | 浮点寄存器     |   |
               |   | (IR, L位)   |          | (FPR, m位)     |   |
               |   +-------------+          +----------------+   |
               |         |                         |             |
               |    指令字长 L                浮点格式位宽 m      |
               +---------|-------------------------|-------------+
                         |                         |
                         v                         v
               +-------------------------------------------------+
               | 主存接口: MDR (存储字长 w 位), MAR (地址位数 k 位)|
               +-------------------------------------------------+
```

#### （1）机器字长（Machine Word Length）
* **定义**：CPU 内部进行**定点整数运算**的数据通路宽度（Datapath Width）。
* **物理决定要素**：算术逻辑单元（ALU）的物理位数、定点通用数据寄存器（General Purpose Registers, GPRs）的位宽以及内部数据总线的位数。
* **硬件对齐规律**：
  * **必须与机器字长严格相同**：ALU 位宽、定点通用寄存器（如 x86 的 EAX/RAX，MIPS 的通用寄存器）、内部基本定点运算数据总线。
  * **不一定与机器字长相同**：
    * 指令寄存器（IR）：其位宽取决于指令字长，可以大于、等于或小于机器字长。
    * 程序计数器（PC）与存储器地址寄存器（MAR）：其位宽取决于主存寻址空间大小（即系统物理地址总线的宽度），与机器字长无绝对必然联系。
    * 浮点寄存器（FPR）：其位宽取决于浮点数表示格式（例如 IEEE 754 单精度为 32 位，双精度为 64 位），可独立于定点机器字长。
    * 存储器数据寄存器（MDR）：其位宽等于存储字长，取决于主存接口总线位宽。

#### （2）存储字长（Storage Word Length）
* **定义**：主存储器中一个存储单元（Storage Cell/Word）所包含的二进制代码总位数。
* **物理决定要素**：存储芯片的数据引脚数以及存储器数据寄存器（MDR）的物理位宽。
* **编址关系**：现代计算机主存普遍按字节（Byte, 8 bits）编址，此时一个存储字可以包含若干个字节（例如 32 位存储字长包含 4 个字节，64 位存储字长包含 8 个字节）。

#### （3）指令字长（Instruction Word Length）
* **定义**：一条机器指令所包含的二进制代码的总位数。
* **结构组成**：由操作码字段（Opcode）和若干地址码/操作数字段（Operand Fields）组成。
* **分类与特征**：
  * **单字长指令**：指令字长等于机器字长。
  * **半字长指令**：指令字长等于半个机器字长。
  * **双字长/多字长指令**：指令字长为机器字长的两倍或多倍。多字长指令需要多次访存才能完整取出，会降低指令执行速率。
  * **定长指令字结构**：指令系统中所有指令的长度均相等（如 RISC 架构经典 32 位定长指令），译码硬件简单，利于流水线设计。
  * **变长指令字结构**：各种指令长度根据功能需要而变化（如 x86 CISC 架构，指令长度可在 1 到 15 字节间变动），格式紧凑，但硬件译码复杂度高。

| 概念类型 | 决定部件 | 典型大小示例 | 与机器字长的关系 |
| :--- | :--- | :--- | :--- |
| **机器字长** | ALU 位数、通用寄存器宽度 | 32 位、64 位 | 基准参考量 |
| **存储字长** | MDR 位数、主存数据引脚 | 32 位、64 位、128 位 | 通常为字节的整数倍，可不等于机器字长 |
| **指令字长** | IR 位数、指令编码格式 | 16 位、32 位、变长 | 可等于、大于或小于机器字长 |

### 2. 机器时间基元与硬件时序生成机理

计算机控制系统必须在精确的时序信号驱动下同步步进。时序系统的层次化结构直接决定了处理器的极限运行频率。

```text
+-----------------------------------------------------------------------------------+
| 指令周期 (Instruction Cycle): 完成一条指令的完整时间 (取指->译码->执行->访存->写回) |
+-----------------------------------------------------------------------------------+
| 机器周期 (Machine Cycle): 访问一次主存或执行一次基本操作的时间 (取指、访存周期等)   |
+-----------------------------------------------------------------------------------+
| 时钟周期 (Clock Cycle, T): 硬件执行最小微操作的时序基元, T = 1 / f                 |
+-----------------------------------------------------------------------------------+
```

#### （1）时钟脉冲信号的物理形成
* **脉冲源与分频**：CPU 的节拍脉冲由高精度的石英晶体振荡器（晶振）产生正弦波基频信号，经整形电路整形为方波脉冲，再通过分频或倍频锁相环（PLL, Phase-Locked Loop）电路生成供给 CPU 各功能单元的时钟脉冲。
* **时钟周期（Clock Cycle / Tick）**：时钟脉冲信号的物理宽度，记为 $T$$ \text{（或} $$\tau$），是 CPU 工作中最小的时间控制单位。
* **主频（Clock Frequency）**：CPU 主时钟的工作频率，记为 $f$，是时钟周期的倒数：
  $$f = \frac{1}{T} \quad (T = \frac{1}{f})$$
  单位通常为 $\text{Hz}$（$\text{MHz}, \text{GHz}$$ \text{）。例如，主频} $$f = 2\text{GHz}$$ \text{时，时钟周期} $$T = \frac{1}{2 \times 10^9\text{s}} = 0.5\text{ns}$。

#### （2）时钟周期长度的底层硬件约束
时钟周期的最小值并非由软件或指令集架构决定，而是直接受限于底层数字逻辑电路的物理传输延迟。

在一个同步时序逻辑系统中，时钟信号驱动触发器（Flip-Flop）或流水段寄存器。时钟周期 $T$ 必须满足以下不等式：
$$T \ge t_{\text{clk-to-q}} + t_{\text{comb\_max}} + t_{\text{setup}} + t_{\text{skew}}$$
其中：
* $t_{\text{clk-to-q}}$：时钟脉冲边沿到达后，触发器输出新状态所需的延迟。
* $t_{\text{comb\_max}}$：**两级相邻状态单元之间组合逻辑电路的最大传播延迟**（关键路径关键延迟）。
* $t_{\text{setup}}$：目标触发器建立时间（Setup Time），即输入数据在时钟采样沿到来前必须保持稳定的最小时间。
* $t_{\text{skew}}$：时钟偏斜（Clock Skew），即时钟信号到达不同寄存器之间的时间偏差。

> **核心结论**：时钟周期的下限取决于**相邻状态单元间组合逻辑电路的最大延迟**（Critical Path Delay）。

#### （3）不同 CPU 架构的时钟周期设计准则
1. **单周期 CPU**：
   * 一条指令的所有执行阶段（取指、译码、执行、访存、写回）必须在一个时钟周期内全部完成。
   * 因此，单周期 CPU 的时钟周期长度**以执行时间最长的那条指令所用的总延迟为准**（在经典 MIPS 架构中，通常是访存加载指令 `LW`，需完整经历五个阶段的逻辑延迟）。
2. **多周期 CPU**：
   * 将指令拆分为若干个等长步骤，每个步骤占用一个时钟周期。时钟周期以各步骤中耗时最长的一个微操作延迟为准。
3. **指令流水线 CPU**：
   * 将指令执行分解为多个独立流水段（如 IF, ID, EX, MEM, WB）。各段由流水段寄存器隔开。
   * 流水线 CPU 的时钟周期**以最长流水段所用的时间为准**，并叠加段间寄存器的锁存延迟：
     $$T_{\text{pipeline}} = \max(t_{\text{segment\_}i}) + t_{\text{reg}}$$

### 3. 核心定量性能指标体系与数学模型

#### （1）CPI 与 IPC
* **CPI（Cycles Per Instruction）**：执行一条指令所需的平均时钟周期数。
  * 单条特定类型指令的周期数为整数或定值（记为 $\text{CPI}_i$）。
  * 包含多种指令类型的程序综合平均 CPI 采用加权平均计算：
    $$\text{CPI} = \sum_{i=1}^n (\text{CPI}_i \times p_i) = \frac{\sum_{i=1}^n (\text{CPI}_i \times N_i)}{N_{\text{total}}}$$
    其中 $p_i$$ \text{为第} $$i$$ \text{类指令在程序中所占比例，} $$N_i$$ \text{为该类指令执行条数，} $$N_{\text{total}}$$ \text{为程序执行的总动态指令条数（Instruction Count,} $$\text{IC}$）。
  * **影响 CPI 的核心因素**：微架构实现方式（单周期处理器 CPI 恒为 1；流水线理想 CPI 为 1，但存在数据相关、控制冒险等气泡）；指令类型配比（乘除法、浮点指令周期长）；**存储系统层次结构性能**（Cache 缺失时引起的流水线停顿周期直接附加在访存指令上，导致程序实际 CPI 显著攀升）。
* **IPC（Instructions Per Cycle）**：每个时钟周期内执行的指令条数，为 CPI 的倒数：
  $$\text{IPC} = \frac{1}{\text{CPI}}$$
  在多发射超标量处理器（Superscalar Processor）中，每个周期可发射多条指令，此时 $\text{IPC} > 1$（$\text{CPI} < 1$）。

#### （2）CPU 执行时间经典三要素方程
CPU 执行时间（$T_{\text{CPU}}$）是衡量处理器性能最纯粹、最具决定性的标准。任何优化手段最终必须反映在总执行时间的削减上：
$$T_{\text{CPU}} = \text{IC} \times \text{CPI} \times T = \frac{\text{IC} \times \text{CPI}}{f}$$

```text
【CPU 性能铁三角】
             T_CPU = (IC * CPI) / f
                     /    |    \
                    /     |     \
          指令条数 IC    CPI   主频 f (1/T)
          [编译器/ISA] [微架构] [硬件半导体工艺/逻辑划分]
```

三个核心变量分别受体系结构不同层级的约束与优化：
1. **动态指令条数（$\text{IC}$）**：受算法逻辑、高级语言编写规范、编译器优化选项以及指令集架构（ISA）直接影响。
2. **平均时钟周期数（$\text{CPI}$）**：受指令集设计、处理器微架构（如分支预测准确率、乱序执行能力、流水线级数）以及 Cache 命中率决定。
3. **主频（$f$$ \text{）/ 时钟周期（} $$T$）**：受半导体工艺制程、电路布线设计以及流水段划分粒度决定。

#### （3）MIPS 与 GIPS
* **MIPS（Million Instructions Per Second）**：每秒执行百万条指令数。
  $$\text{MIPS} = \frac{\text{IC}}{T_{\text{CPU}} \times 10^6} = \frac{\text{IC}}{\frac{\text{IC} \times \text{CPI}}{f} \times 10^6} = \frac{f}{\text{CPI} \times 10^6} = \frac{f (\text{MHz})}{\text{CPI}}$$
* **GIPS（Giga Instructions Per Second）**：每秒执行十亿条指令数。
  $$\text{GIPS} = \frac{f}{\text{CPI} \times 10^9} = \frac{f (\text{GHz})}{\text{CPI}}$$

> **MIPS 指标的局限性与失真陷阱**：
> 1. MIPS 未考虑不同指令功能的强弱差异。复杂指令系统（CISC）单条指令能完成复杂的运算，动态指令数 $\text{IC}$$ \text{较少；精简指令系统（RISC）单条指令操作简单，完成相同任务需要更多的指令数} $$\text{IC}$。因此，RISC 计算机的 MIPS 往往很高，但完成相同程序的实际耗时未必优于 CISC 计算机。
> 2. MIPS 依赖于特定程序的指令组合分布，同台机器运行不同负载测得的 MIPS 完全不同。
> 3. **结论**：MIPS 绝不能用于跨指令集架构（Cross-ISA）的机器性能横向对比！

#### （4）FLOPS 阶梯换算体系
* **FLOPS（Floating-point Operations Per Second）**：每秒执行浮点操作次数。
* 浮点运算通常涉及尾数对齐、加减运算、规格化舍入及指数调整等复杂时序，是科学计算、图形渲染、人工智能领域的决定性性能基准。
* **十进制国际前缀阶梯（严格按 $10^3$ 递增）**：
  $$\begin{aligned}
  1\ \text{KFLOPS} &= 10^3\ \text{FLOPS} \quad (\text{千}) \\
  1\ \text{MFLOPS} &= 10^6\ \text{FLOPS} \quad (\text{兆}) \\
  1\ \text{GFLOPS} &= 10^9\ \text{FLOPS} \quad (\text{吉}) \\
  1\ \text{TFLOPS} &= 10^{12}\ \text{FLOPS} \quad (\text{太}) \\
  1\ \text{PFLOPS} &= 10^{15}\ \text{FLOPS} \quad (\text{拍}) \\
  1\ \text{EFLOPS} &= 10^{18}\ \text{FLOPS} \quad (\text{艾})
  \end{aligned}$$

### 4. 吞吐率与响应时间的系统级辩证解析

* **响应时间（Response Time / Latency）**：用户从提交作业到系统完成该作业所经历的完整时间间隔，包括 CPU 计算时间、I/O 访存等待时间、操作系统进程调度开销等。
* **吞吐率（Throughput / Bandwidth）**：系统在单位时间内所完成的工作量或任务总数（如每秒处理的事务数 TPS、网络每秒传输的数据比特数 bps）。
* **二者的辩证关系**：
  * **单任务优化**：缩短单个任务的执行时间通常能够直接改善吞吐率。
  * **并发/流水线技术对响应时间的潜在代价**：通过引入多核并行或深度指令流水线，系统的吞吐率得以成倍提升；但由于流水段寄存器的建立与传输延迟、多核总线仲裁排队以及上下文切换开销，单个独立任务的响应时间往往不仅没有缩短，反而可能略有微小增加。

```text
【单处理器顺序执行 vs 指令流水线执行对比】
顺序执行:  [任务1]-----> [任务2]-----> [任务3]-----> [任务4]----->
          (响应时间最短, 但各硬件部件利用率低, 吞吐率受限)

流水重叠:  [IF1][ID1][EX1][MEM1][WB1]
                [IF2][ID2][EX2][MEM2][WB2]
                     [IF3][ID3][EX3][MEM3][WB3]
          (吞吐率大幅提升; 单个指令受寄存器延迟累加, 绝对响应时间略增)
```

### 5. 基准测试程序（Benchmark）评估原理

由于单一指标（如主频、MIPS、MFLOPS）在衡量全系统综合性能时存在严重片面性，现代计算机体系结构普遍采用**基准测试程序（Benchmark Suites）**来进行客观评价：
* **核心原理**：选取能够代表典型工作负载（Workload）的实际应用程序集合，编译并在目标平台上运行，记录各程序的实际执行时间，并与预设的参考基准机器进行比对。
* **SPEC CPU（Standard Performance Evaluation Corporation）**：业界最权威的基准测试集。
  * 计算各分项基准程序的执行时间相对于标准参考机器执行时间的比值：
    $$r_i = \frac{T_{\text{Reference}, i}}{T_{\text{Target}, i}}$$
  * 采用**几何平均数（Geometric Mean）**综合计算总体性能得分：
    $$\text{SPECratio} = \sqrt[n]{\prod_{i=1}^n r_i}$$
    几何平均数能够有效避免不同程序绝对耗时量级差异对最终得分的权重扭曲，具有良好的数学独立性。

### 6. 经典学术误区与命题陷阱深剖

#### 陷阱一：主频高一定代表计算机运行速度更快？
* **辨析**：**错误**。
* **底层原理**：由 $T_{\text{CPU}} = \frac{\text{IC} \times \text{CPI}}{f}$$ \text{可知，主频} $$f$ 仅是决定性能的三大要素之一。
  * 若某处理器的流水线级数极深（如经典的 Intel Pentium 4 净级数达 20~31 级），流水段非常简短，主频极易冲至很高；但由于过深的流水线导致分支预测错误惩罚激增、冒险停顿剧烈，整体加权 $\text{CPI}$ 大幅增大。
  * 若另一处理器具有先进的乱序执行、超标量架构与高命中率 Cache，其 $\text{CPI}$$ \text{极低（例如多发射} $$\text{IPC} > 2$$ \text{），即使主频较低，其实际完成程序的执行时间} $$T_{\text{CPU}}$ 也远小于高主频处理器。

#### 陷阱二：Cache 缺失率与 CPI 无关？
* **辨析**：**错误**（2025 年统考第 18 题考点）。
* **底层原理**：当执行加载（LOAD）或存储（STORE）访存指令时，若发生 Cache 缺失，CPU 必须强制暂停流水线（Stall），向速度较慢的下一级存储器或主存发起总线请求并等待数据返回。该等待周期被称为缺失惩罚（Miss Penalty）。缺失周期直接累加到该访存指令的时钟周期中，必然导致该指令及整段程序的平均 $\text{CPI}$ 上升：
  $$ \text{CPI}_{\text{actual}} = \text{CPI}_{\text{ideal}} + (\text{访存指令占比} \times \text{Cache 缺失率} \times \text{缺失惩罚周期}) $$

#### 陷阱三：前缀单位 $K, M, G$ 混用计算错误
* **辨析**：必须严格区分两种上下文：
  1. **描述存储容量、地址范围、以字节（B）或字为单位**：采用二进制指数，严格以 $2^{10} = 1024$ 为基底。
     $$\text{1KB} = 2^{10}\text{B} = 1024\text{B}, \quad \text{1MB} = 2^{20}\text{B}, \quad \text{1GB} = 2^{30}\text{B}$$
  2. **描述时钟频率（Hz）、数据传输速率（bps/Bps）、指令执行速率（MIPS/FLOPS）**：属于国际通用计量度量衡，严格以十进制 $10^3 = 1000$ 为基底。
     $$\text{1kHz} = 10^3\text{Hz}, \quad \text{1MHz} = 10^6\text{Hz}, \quad \text{1GHz} = 10^9\text{Hz}, \quad \text{1PFLOPS} = 10^{15}\text{FLOPS}$$

### 【真题 1】2016 年 408 统考第 44 题 · CPU 性能指标与中断 I/O 综合计算

**题目**  
假定 CPU 主频为 50MHz，CPI 为 4。设备 D 采用异步串行通信方式向主机传送 7 位 ASCII 字符，通信规程中有 1 位奇校验位和 1 位停止位，从 D 接收启动命令到字符送入 I/O 端口需要 0.5ms。请回答下列问题，要求说明理由。  
(1) 每传送一个字符，在异步串行通信线上共需传输多少位？在设备 D 持续工作过程中，每秒钟最多可向 I/O 端口送入多少个字符？  
(2) 设备 D 采用中断方式进行输入/输出，示意图如下：  

```text
CPU       +----+ 请求 响应 +---------------------+ 返回   +----+ 请求 响应 ...
          |    |---------->| 执行中断服务程序    |------->|    |---------->
          +----+           +---------------------+        +----+
                             ^ 启动 (第15条指令)
                             |
外设 D    +------------------+-----------------------------+
          | 工作 (0.5ms)     | 完成并申请中断              | 工作 ...
          +------------------+-----------------------------+
```

I/O 端口每收到一个字符申请一次中断，中断响应需 10 个时钟周期，中断服务程序共有 20 条指令，其中第 15 条指令启动 D 工作。若 CPU 需从 D 读取 1000 个字符，则完成这一任务所需时间大约是多少个时钟周期？CPU 用于完成这一任务的时间大约是多少个时钟周期？在中断响应阶段 CPU 进行了哪些操作？

#### 【解析】
1. **第 (1) 问解析**：
   * **异步串行通信帧格式**：在典型的异步串行通信规程中，数据帧由**起始位**引导，随后为数据位、校验位，最后以**停止位**结束。
   * 必须包含 1 位起始位（低电平）；题目给出 7 位 ASCII 数据位、1 位奇校验位、1 位停止位（高电平）。
   * 每传送一个字符在线上实际传输的总位数为：
     $$ \text{N_{\text{bit}} = 1\ (\text{起始位}) + 7\ (\text{数据位}) + 1\ (\text{奇校验位}) + 1\ (\text{停止位}) = 10\ \text{位}} $$
   * **持续工作最大传送率**：外设从启动到将字符送入 I/O 端口耗时 $0.5\text{ms}$。因此每秒钟可连续送入的字符数上限为：
     $$ \text{N_{\text{char/s}} = \frac{1\text{s}}{0.5\text{ms}} = \frac{1000\text{ms}}{0.5\text{ms}} = 2000\ \text{个/秒}} $$

2. **第 (2) 问解析**：
   * **基础时序参数换算**：
     CPU 主频 $f = 50\text{MHz}$$ \text{，单个时钟周期} $$T = \frac{1}{50\text{MHz}} = 20\text{ns}$。
     设备 D 准备一个字符耗时 $0.5\text{ms} = 500\mu\text{s} = 500,000\text{ns}$，换算为 CPU 时钟周期数：
     $$ \text{C_{\text{device}} = \frac{0.5\text{ms}}{20\text{ns}} = \frac{500,000\text{ns}}{20\text{ns}} = 25,000\ \text{个时钟周期} \quad (2.5 \times 10^4)} $$
   * **分析 CPU 与外设 D 并行工作时序**：
     * 设备 D 准备字符耗时 25,000 周期后向 CPU 发出中断请求。
     * CPU 中断响应耗时 10 个时钟周期。
     * 进入中断服务程序，执行前 15 条指令。因平均 $\text{CPI} = 4$，执行前 15 条指令耗费：
       $$ \text{C_{\text{pre15}} = 15 \times 4 = 60\ \text{个时钟周期}} $$
     * 在第 15 条指令执行完成瞬间，CPU 向外设 D 发出启动命令，外设 D 立即开始准备下一个字符（重新经历 25,000 周期）。
     * 与此同时，CPU 继续执行该中断服务程序剩余的 5 条指令（耗时 $5 \times 4 = 20$$ \text{周期）并返回主程序。因} $$25,000 \gg 20$，外设 D 准备下个字符所需时间完全掩盖了中断服务程序的后续执行。
     * 故传送一个字符的循环周期（两次启动外设之间的时钟周期间隔）为：
       $$ \text{C_{\text{cycle}} = C_{\text{device}} + C_{\text{resp}} + C_{\text{pre15}} = 25,000 + 10 + 60 = 25,070\ \text{个时钟周期}} $$
   * **完成 1000 个字符所需总时间**：
     * 前 999 个字符均以 25,070 周期循环推进。对于第 1000 个字符，CPU 必须完整执行完最后的全部 20 条中断服务指令方可宣告任务终结。
     * 严格精细计算：
       $$ \text{T_{\text{total}} = 999 \times 25,070 + (25,000 + 10 + 20 \times 4) = 25,044,930 + 25,090 = 25,070,020\ \text{个时钟周期}} $$
     * 工程近似计算：传送 1000 个字符大约需要：
       $$ \text{1000 \times 25,070 = 25,070,000\ \text{个时钟周期} \quad (\text{两答案均可得分})} $$
   * **CPU 用于该任务的时间计算**：
     * CPU 仅在处理中断时占用时钟，每个字符占用 CPU 的时间包括：中断响应阶段（10 周期）以及完整执行 20 条中断服务程序指令的时间（$20 \times 4 = 80$ 周期）。
     * 单个字符耗费 CPU 时间：$C_{\text{CPU/char}} = 10 + 80 = 90$ 个时钟周期。
     * 读取 1000 个字符，CPU 用于该任务的总时间为：
       $$ \text{C_{\text{CPU\_total}} = 1000 \times 90 = 90,000 = 9 \times 10^4\ \text{个时钟周期}} $$
   * **中断响应阶段 CPU 的操作（中断隐指令执行）**：
     1. **关中断**：将中断允许触发器清零，屏蔽后续同级或更低优先级中断。
     2. **保护断点和程序状态**：将当前程序计数器（PC）和程序状态字（PSW）推入系统堆栈或保存至特定暂存寄存器。
     3. **引出中断服务程序**：识别中断源，读取中断向量并将中断向量地址或服务程序入口送入 PC。

#### 【正确答案】
(1) 线上共需传输 10 位；每秒最多送入 2000 个字符。  
(2) 完成任务所需时间大约为 25,070,000 个时钟周期（或 25,070,020 周期）；CPU 用于完成该任务的时间大约为 $9 \times 10^4$ 个时钟周期；中断响应阶段 CPU 进行的操作包括关中断、保护断点和程序状态、识别中断源并引出中断服务程序。

### 【真题 2】2018 年 408 统考第 43 题 · CPU 性能方程与多 I/O 方式占空比分析

**题目**  
假定计算机的主频为 500MHz，CPI 为 4。现有设备 A 和 B，其数据传输率分别为 2MBps 和 40MBps，对应 I/O 接口中各有一个 32 位数据缓冲寄存器。请回答下列问题，要求给出计算过程。  
(1) 若设备 A 采用定时查询 I/O 方式，每次输入/输出都至少执行 10 条指令。设备 A 最多间隔多长时间查询一次才能不丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？  
(2) 在中断 I/O 方式下，若每次中断响应和中断处理的总时钟周期数至少为 400，则设备 B 能否采用中断 I/O 方式？为什么？  
(3) 若设备 B 采用 DMA 方式，每次 DMA 传送的数据块大小 1000B，CPU 用于 DMA 预处理和后处理的总时钟周期数为 500，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最大是多少？

#### 【解析】
1. **第 (1) 问解析**：
   * 接口数据缓冲寄存器为 32 位，即 $4\text{B}$$ \text{。设备 A 传输率为} $$2\text{MBps} = 2 \times 10^6\text{B/s}$。
   * 缓冲寄存器被连续数据填满的时间间隔即为定时查询的最大允许间隔，超过该间隔数据将被新到达字节冲刷覆盖：
     $$T_{\text{interval}} = \frac{4\text{B}}{2\text{MB/s}} = \frac{4\text{B}}{2 \times 10^6\text{B/s}} = 2 \times 10^{-6}\text{s} = 2\mu\text{s}$$
   * 故最多每隔 $2\mu\text{s}$ 必须查询一次。
   * **CPU 查询开销分析**：
     * 每秒所需的最少查询次数为：$$ \text{N = \frac{1\text{s}}{2\mu\text{s}} = 5 \times 10^5\ \text{次}} $$。
     * 每次查询需执行至少 10 条指令，每条指令平均需要 4 个时钟周期，故每次查询耗时 $10 \times 4 = 40$ 个时钟周期。
     * 每秒 CPU 用于设备 A 输入/输出的时钟周期数至少为：
       $$ \text{C_{\text{query/s}} = 5 \times 10^5 \times 40 = 2 \times 10^7\ \text{个时钟周期}} $$
     * CPU 主频为 $500\text{MHz}$$ \text{，即每秒总计提供} $$500 \times 10^6 = 5 \times 10^8$ 个时钟周期。
     * CPU 用于设备 A 的时间百分比至少为：
       $$\eta = \frac{2 \times 10^7}{5 \times 10^8} \times 100\% = 4\%$$

2. **第 (2) 问解析**：
   * 设备 B 传输速率为 $40\text{MBps} = 40 \times 10^6\text{B/s}$$ \text{，缓冲区大小同样为} $$32\text{位} = 4\text{B}$。
   * 设备 B 填满缓冲区所需时间为：
     $$T_{\text{fill}} = \frac{4\text{B}}{40 \times 10^6\text{B/s}} = 0.1 \times 10^{-6}\text{s} = 0.1\mu\text{s} = 100\text{ns}$$
   * 中断响应加处理至少需要 400 个时钟周期。在主频 $500\text{MHz}$$ \text{（时钟周期} $$T = 2\text{ns}$）下，中断服务总耗时至少为：
     $$T_{\text{int}} = 400 \times 2\text{ns} = 800\text{ns} = 0.8\mu\text{s}$$
   * 显然，$T_{\text{int}} (0.8\mu\text{s}) > T_{\text{fill}} (0.1\mu\text{s})$。这意味着在 CPU 尚未处理完毕前一次中断并读走数据前，下一个数据就已经涌入缓冲区并破坏前序内容，导致数据溢出丢失。因此设备 B 不能采用中断 I/O 方式。

3. **第 (3) 问解析**：
   * DMA 传输模式下，成块数据的传送完全由 DMA 控制器硬件通过总线周期挪用完成，CPU 仅在数据块传送前后介入执行初始化（预处理）和中断收尾（后处理）。
   * 数据块大小为 $1000\text{B}$$ \text{，设备 B 传输率为} $$40\text{MBps}$。每秒最多发生的 DMA 传输块数为：
     $$ \text{N_{\text{DMA}} = \frac{40 \times 10^6\text{B/s}}{1000\text{B}} = 40,000\ \text{次/秒} = 4 \times 10^4\ \text{次/秒}} $$
   * 每次 DMA 请求占用 CPU 预处理与后处理总计 500 个时钟周期。
   * 每秒 CPU 用于设备 B 输入/输出的时钟周期数上限为：
     $$ \text{C_{\text{DMA/s}} = 40,000 \times 500 = 2 \times 10^7\ \text{个时钟周期}} $$
   * 故 CPU 占用时间百分比最大为：
     $$\eta_{\text{max}} = \frac{2 \times 10^7}{5 \times 10^8} \times 100\% = 4\%$$

#### 【正确答案】
(1) 最多间隔 $2\mu\text{s}$$ \text{查询一次；CPU 用于设备 A 的时间百分比至少为} $$4\%$。  
(2) 设备 B 不能采用中断方式，因为中断处理耗时（$0.8\mu\text{s}$$ \text{）大于缓冲区填满时间（} $$0.1\mu\text{s}$），会导致数据覆盖丢失。  
(3) CPU 用于设备 B 的时间百分比最大为 $4\%$。

### 【真题 3】2019 年 408 统考第 16 题 · 时钟脉冲与时序逻辑底层特性

**题目**  
下列有关处理器时钟脉冲信号的叙述中，错误的是（ ）。  
A. 时钟脉冲信号由机器脉冲源发出的脉冲信号经整形和分频后形成  
B. 时钟脉冲信号的宽度称为时钟周期，时钟周期的倒数为机器主频  
C. 时钟周期以相邻状态单元间组合逻辑电路的最大延迟为基准确定  
D. 处理器总是在每来一个时钟脉冲信号时就开始执行一条新的指令  

#### 【解析】
* **选项 A 正确**：主板晶体振荡器产生高频正弦振荡，经由脉冲整形逻辑转变为方波，再由数字分频器和倍频锁相环（PLL）电路派生出稳定的处理器时钟节拍。
* **选项 B 正确**：时钟脉冲宽度或两个相邻边沿的时间间隔即为时钟周期 $T$$ \text{，主频} $$f = 1/T$。
* **选项 C 正确**：同步时序逻辑电路中，数据在时钟节拍驱动下从一组触发器流向下一组触发器。为了保证数据在建立时间内稳定建立，时钟周期必须大于关键路径上组合逻辑电路的最大延迟与触发器寄生延迟之和。
* **选项 D 错误**：执行一条新指令需根据 CPU 架构而定。在多周期 CPU 中，一条指令往往需要 3~5 个时钟周期甚至更多时钟周期逐步完成，只有在每条指令的最后一个周期结束后才开启新指令；在流水线处理器中，虽然理想状态下一个周期发射一条指令，但在流水线发生停顿、分支预测失败清空或结构冒险气泡时，并不是每个脉冲都会开始执行新指令；在单周期处理器中，也是在时钟周期起始执行指令，而非任意脉冲均开始新指令。因此“总是在每来一个时钟脉冲信号时就开始执行一条新的指令”完全违背事实。

#### 【正确答案】
**D**

### 【真题 4】2020 年 408 统考第 12 题 · 硬件部件位宽与机器字长对齐关系

**题目**  
下列给出的部件中其位数（宽度）一定与机器字长相同的是（ ）。  
I. ALU &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; II. 指令寄存器 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; III. 通用寄存器 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; IV. 浮点寄存器  
A. I、II &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. I、III &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. II、III &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. II、III、IV  

#### 【解析】
* **机器字长的本质定义**：CPU 内部定点数据通路的核心处理宽度，决定了内部定点运算的基本精度。
* **部件 I 分析（ALU）**：ALU 承担机器核心的定点算术逻辑运算。ALU 的操作数输入端和输出端宽度直接等于定点数据通路宽度，即机器字长。**一定相同**。
* **部件 II 分析（指令寄存器 IR）**：IR 存放当前正被执行的机器指令代码，其宽度完全取决于系统中的指令字长。在变长指令系统（如 x86）或多字长指令系统中，指令字长可以为 8 位、16 位、32 位甚至 120 位，与机器字长并不强制相等。**不一定相同**。
* **部件 III 分析（通用寄存器 GPR）**：通用寄存器存放参与整数运算的操作数或中间结果，属于定点数据通路上的核心暂存部件，必须与 ALU 的位宽严格匹配才能无损传输数据。因此定点通用寄存器宽度一定等于机器字长。**一定相同**。
* **部件 IV 分析（浮点寄存器 FPR）**：专门用于暂存浮点操作数。其位宽由浮点数表示规范（如 IEEE 754 标准，单精度 32 位，双精度 64 位）决定。例如在经典的 32 位机器中，可以拥有 64 位或 80 位的浮点寄存器。**不一定相同**。
* 综上，仅 I 和 III 正确。

#### 【正确答案】
**B**

### 【真题 5】2021 年 408 统考第 12 题 · 超级计算机浮点性能阶梯与单位前缀

**题目**  
2017 年公布的全球超级计算机 TOP500 排名中，我国“神威·太湖之光”超级计算机蝉联第一，其浮点运算速度为 93.0146PFLOPS，说明该计算机每秒钟完成的浮点操作次数为（ ）。  
A. $9.3 \times 10^{13}$$ \text{次 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B.} $$9.3 \times 10^{15}$ 次 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 9.3 千万亿次 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 9.3 亿亿次  

#### 【解析】
1. **科学计数度量前缀推导**：
   根据国际单位制（SI）：
   * $\text{K} = 10^3$（千）
   * $\text{M} = 10^6$（兆）
   * $\text{G} = 10^9$（吉）
   * $\text{T} = 10^{12}$（太）
   * $\text{P} = 10^{15}$（拍）
2. **总量换算**：
   $$93.0146\ \text{PFLOPS} \approx 93 \times 10^{15}\ \text{FLOPS} = 9.3 \times 10^{16}\ \text{FLOPS}$$
3. **中文计数单位映射**：
   * 1 万 $= 10^4$
   * 1 亿 $= 10^8$
   * 1 千万亿 $= 10^7 \times 10^8 = 10^{15}$
   * 1 亿亿 $= 10^8 \times 10^8 = 10^{16}$
4. 因此，$9.3 \times 10^{16}$ 次对应为 9.3 亿亿次。选项 D 正确。

#### 【正确答案】
**D**

### 【真题 6】2022 年 408 统考第 12 题 · 加权平均 CPI 与 CPU 执行时间推导

**题目**  
某计算机主频为 1GHz，程序 P 运行过程中，共执行了 10000 条指令，其中，80% 的指令执行平均需 1 个时钟周期，20% 的指令执行平均需 10 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是（ ）。  
A. 2.8，28$\mu$s &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. 28，28$\mu$s &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 2.8，28ms &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 28，28ms  

#### 【解析】
1. **加权平均 CPI 计算**：
   程序共包含两类指令分布，应用 CPI 加权公式：
   $$\text{CPI} = 80\% \times 1 + 20\% \times 10 = 0.8 + 2.0 = 2.8$$
2. **CPU 执行时间计算**：
   * 计算机主频 $f = 1\text{GHz} = 1 \times 10^9\text{Hz}$。
   * 指令总条数 $\text{IC} = 10000 = 10^4$ 条。
   * 代入 CPU 性能方程：
     $$T_{\text{CPU}} = \frac{\text{IC} \times \text{CPI}}{f} = \frac{10000 \times 2.8}{1 \times 10^9\text{Hz}} = \frac{28000}{10^9}\text{s} = 2.8 \times 10^{-5}\text{s}$$
   * 进行时间单位换算（$1\text{s} = 10^6\mu\text{s}$）：
     $$T_{\text{CPU}} = 2.8 \times 10^{-5} \times 10^6\mu\text{s} = 28\mu\text{s}$$
3. 对照各选项，平均 CPI 为 2.8，执行时间为 $28\mu\text{s}$，对应 A 项。

#### 【正确答案】
**A**

### 【真题 7】2023 年 408 统考第 12 题 · 指令速率 GIPS 与用户 CPU 时间双向推导

**题目**  
若机器 M 的主频为 1.5GHz，在 M 上执行程序 p 的指令条数为 $5 \times 10^5$，p 的平均 CPI 为 1.2，则 p 在 M 上的指令执行速度和用户 CPU 时间分别为（ ）。  
A. 0.8GIPS、0.4ms &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. 0.8GIPS、0.4$\mu$s &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 1.25GIPS、0.4ms &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 1.25GIPS、0.4$\mu$s  

#### 【解析】
1. **指令执行速度（GIPS）计算**：
   * 主频 $f = 1.5\text{GHz} = 1.5 \times 10^9\text{Hz}$$ \text{，即每秒产生} $$1.5 \times 10^9$ 个时钟周期。
   * 平均执行一条指令需消耗 1.2 个时钟周期。
   * 每秒执行的指令条数（以 Giga 为单位）：
     $$ \text{速度} = \frac{f}{\text{CPI} \times 10^9} = \frac{1.5 \times 10^9}{1.2 \times 10^9} = 1.25\ \text{GIPS} $$
2. **用户 CPU 时间计算**：
   * 动态指令数 $\text{IC} = 5 \times 10^5$。
   * 总时钟周期数 $C_{\text{total}} = \text{IC} \times \text{CPI} = 5 \times 10^5 \times 1.2 = 6 \times 10^5$ 个周期。
   * 用户 CPU 执行时间：
     $$T_{\text{CPU}} = \frac{C_{\text{total}}}{f} = \frac{6 \times 10^5}{1.5 \times 10^9\text{Hz}} = 4 \times 10^{-4}\text{s}$$
   * 换算为毫秒（$1\text{s} = 1000\text{ms}$）：
     $$T_{\text{CPU}} = 4 \times 10^{-4} \times 10^3\text{ms} = 0.4\text{ms}$$
3. 综合判断，指令速度为 1.25GIPS，CPU 时间为 0.4ms，对应 C 项。

#### 【正确答案】
**C**

### 【真题 8】2025 年 408 统考第 18 题 · 处理器架构基准与 CPI 关联综合辨析

**题目**  
下列关于 CPI 和 CPU 时钟周期的叙述中，错误的是（ ）。  
A. 不同类型指令的 CPI 可能不一样  
B. 程序的 CPI 与 Cache 缺失率无关  
C. 单周期 CPU 的时钟周期以最耗时指令所用的时间为准  
D. 流水线 CPU 的时钟周期以最长流水段所用时间为准  

#### 【解析】
* **选项 A 正确**：在现代处理器中，简单的逻辑按位与指令、加法指令通常仅需 1 个时钟周期；而多周期乘除法指令、浮点平方根指令往往需要数十个时钟周期。指令类型不同，其固有 CPI 存在客观差异。
* **选项 B 错误**：Cache 缺失是引发处理器流水线暂停（Pipeline Stall）的主要来源。当执行访存指令发生 Cache 缺失时，CPU 必须等待较慢的底层主存填充缓存块，导致该访存指令被严重阻塞数百个周期（缺失惩罚）。访存停顿周期直接附加在指令原本的执行时间之上，因此程序的平均 CPI 随 Cache 缺失率的升高而急剧恶化。
* **选项 C 正确**：单周期处理器的微架构设计强制所有指令都在一个单一的时钟周期内完成所有数据通路阶段（取指、译码、执行、访存、写回）。为保证逻辑最复杂、延迟最长的指令（如访存读取 `LOAD`）能够在时钟脉冲结束前完成数据稳定，系统的时钟周期长度必须以该最耗时指令的总延迟为基准进行设计。
* **选项 D 正确**：流水线处理器将指令执行划分为多个子阶段。为保证每个阶段均能在同一个时钟节拍内完成锁存，流水线的时钟周期必须足以容纳耗时最长的流水段延迟（加上流水段间锁存器的固有建立与传播开销）。

#### 【正确答案】
**B**

## 四、 综合大题应用与考查拓展

在 408 综合应用大题中，计算机性能指标从不孤立出现，而是作为贯穿“CPU 数据通路—存储体系—I/O 接口”的统一数学纽带。考生需熟练掌握以下三大综合考查模型：

```text
+---------------------------------------------------------------------------------------+
|                               408 综合大题性能计算模型矩阵                                |
+------------------------------------+--------------------------------------------------+
| 交叉融合模块                       | 核心物理参量与计算方程                             |
+------------------------------------+--------------------------------------------------+
| CPU 数据通路与流水线               | 时钟周期确定: tau = max(t_i) + t_reg             |
|                                    | 实际吞吐率: TP = n / [(k + n - 1 + Stall) * tau] |
|                                    | 冒险气泡拉升实际 CPI: CPI = 1 + Stalls / n       |
+------------------------------------+--------------------------------------------------+
| 存储层次体系 (Cache / 主存)        | 平均访存时间: AMAT = t_hit + MissRate * Penalty  |
|                                    | 实际 CPI: CPI_act = CPI_base + 缺失停顿周期      |
+------------------------------------+--------------------------------------------------+
| 输入输出系统 (I/O)                 | 查询间隔: T_int = Buffer / Bandwidth             |
|                                    | CPU 占空比: eta = (每秒查询/中断周期数) / f      |
+------------------------------------+--------------------------------------------------+
```

### 1. 指令流水线性能与 CPU 执行时间综合联动

在流水线 CPU 设计题（第 43/44 题）中，指令相关、分支跳转预测失败均会产生流水线停顿（Stall Cycles / 气泡），从而拉低整体性能。

#### （1）时钟周期的精确判定
设一条 $k$$ \text{级流水线各段的操作时间分别为} $$t_1, t_2, \dots, t_k$$ \text{，各段间寄存器的延迟为} $$t_{\text{reg}}$，则流水线时钟周期必须满足：
$$\tau = \max(t_1, t_2, \dots, t_k) + t_{\text{reg}}$$

#### （2）气泡对 CPI 与加速比的定量影响
* 若理想状态下无任何冒险，连续执行 $n$$ \text{条指令总共需要} $$(k + n - 1)$ 个时钟周期。
* 当存在 $S_{\text{stall}}$ 个时钟周期的冒险停顿（如条件跳转预测失败清空流水线耗费 3 周期，Load-Use 数据冒险停顿 1 周期）时，执行总时钟周期变为：
  $$C_{\text{total}} = (k + n - 1) + S_{\text{stall}}$$
* **程序实际运行 CPI**：
  $$\text{CPI}_{\text{actual}} = \frac{C_{\text{total}}}{n} = \frac{k + n - 1 + S_{\text{stall}}}{n} \xrightarrow{n \to \infty} 1 + \frac{S_{\text{stall}}}{n}$$
* **流水线加速比（Speedup Ratio）**：
  $$S = \frac{T_{\text{non-pipeline}}}{T_{\text{pipeline}}} = \frac{n \times \sum_{i=1}^k t_i}{C_{\text{total}} \times \tau}$$

---

### 2. 存储层次结构与 CPI 联动（AMAT 与缺失惩罚）

存储系统的不命中惩罚直接决定了 CPU 内部访存指令的真实执行开销。

#### （1）平均访存时间（Average Memory Access Time, AMAT）
$$\text{AMAT} = t_{\text{hit}} + \text{Miss Rate} \times \text{Miss Penalty}$$
若考虑多级 Cache（L1 Cache 与 L2 Cache）：
$$\text{AMAT} = t_{\text{L1\_hit}} + \text{MissRate}_{\text{L1}} \times (t_{\text{L2\_hit}} + \text{MissRate}_{\text{L2}} \times \text{Penalty}_{\text{Mem}})$$

#### （2）Cache 缺失对程序 CPU 执行时间的拉升方程
设基准理想 CPI 为 $\text{CPI}_{\text{base}}$$ \text{（即假设主存/Cache 每次访问} $$100\%$$ \text{命中），程序中指令访存与数据访存的统计规律为：每条指令平均产生} $$M$$ \text{次访存（例如：取指产生 1 次，另外有} $$30\%$$ \text{的指令为 Load/Store 访存指令，则} $$M = 1.3$）。
$$\text{CPI}_{\text{actual}} = \text{CPI}_{\text{base}} + M \times \text{Miss Rate} \times \text{Miss Penalty}$$
代入 CPU 执行时间方程：
$$T_{\text{CPU}} = \text{IC} \times \left( \text{CPI}_{\text{base}} + M \times \text{Miss Rate} \times \text{Miss Penalty} \right) \times T$$

---

### 3. I/O 系统数据传输率与 CPU 占空比计算模板

历年综合应用题（如 2016#44、2018#43）常要求评估 I/O 对 CPU 资源的消耗程度。

#### （1）定时查询方式下 CPU 占用比计算模板
1. **确定最大允许查询间隔**：
   $$ \text{T_{\text{max}} = \frac{\text{接口数据缓冲寄存器容量}}{\text{外设数据传输速率}}} $$
2. **计算每秒查询次数**：$N_{\text{query}} = \frac{1\text{s}}{T_{\text{max}}}$。
3. **计算每次查询耗费时钟数**：$$ \text{C_{\text{query}} = \text{指令条数} \times \text{CPI}} $$。
4. **计算 CPU 占空比**：
   $$\eta_{\text{CPU}} = \frac{N_{\text{query}} \times C_{\text{query}}}{f_{\text{CPU}}} \times 100\%$$

#### （2）中断方式下设备能否接入的判据
外设数据缓冲寄存器填满所需的时间 $T_{\text{fill}}$ 为外设申请中断的周期：
$$ \text{T_{\text{fill}} = \frac{\text{接口缓冲容量}}{\text{外设数据传输速率}}} $$
若系统完成一次完整的中断处理所需的最小时间（中断响应时间 + 中断服务程序执行时间）为 $T_{\text{service}}$：
* **充分必要条件**：必须满足 $T_{\text{service}} \le T_{\text{fill}}$。
* **失效判定**：若 $T_{\text{service}} > T_{\text{fill}}$，则在前序数据未被取走前新数据强制写入，引发数据覆盖丢失，**该设备绝对不能采用中断方式**。

#### （3）DMA 方式下 CPU 占空比计算模板
1. **计算每秒 DMA 触发中断次数**：
   $$ \text{N_{\text{DMA}} = \frac{\text{外设数据传输率}}{\text{DMA 单次传输数据块大小}}} $$
2. **计算 CPU 占用的周期数**：CPU 仅执行预处理和后处理，单次耗费时钟数 $C_{\text{DMA}}$。
3. **计算 CPU 占空比**：
   $$\eta_{\text{DMA}} = \frac{N_{\text{DMA}} \times C_{\text{DMA}}}{f_{\text{CPU}}} \times 100\%$$

### 4. 易错避坑核心法则

1. **时钟周期确定陷阱**：
   * 单周期 CPU：以**执行耗时最长的那条指令**为准（而非平均值）。
   * 流水线 CPU：以**耗时最长的那一个流水段延迟**加上锁存器延迟为准（而非所有段的平均值）。
2. **CPI 与 Cache 缺失关联陷阱**：
   * 极易误选“程序的 CPI 是固有常量”。必须牢记：**Cache 缺失停顿直接计入指令执行周期**，降低 Cache 缺失率能大幅降低程序实际 CPI。
3. **MIPS 跨架构对比陷阱**：
   * MIPS 高不等于速度快。RISC 指令简单但条数多，MIPS 往往高于 CISC，但最终程序执行时间取决于 $\text{IC} \times \text{CPI} \times T$。
4. **中断与 DMA 的 CPU 时间区分**：
   * 中断方式下，每个传输单元（字符/字）都需要经历中断响应 + 完整中断服务程序；
   * DMA 方式下，成块传送过程完全不消耗 CPU 时钟，CPU 仅在**预处理（初始化寄存器）**与**后处理（中断校验状态）**消耗极少量的时钟周期。
