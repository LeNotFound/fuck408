## 二、 具体考察内容

### 1. 存储芯片外部引脚与内部阵列架构

半导体存储芯片内部由存储阵列、地址译码器、读写控制逻辑以及双向三态数据缓冲器构成。外部引脚按功能分为三类：

1. **地址引脚（$A_n \sim A_0$）**：
   * 单向输入信号，用于传送 CPU 产生的存储单元地址。
   * 地址引脚数 $k$$ \text{与芯片内部可寻址的存储单元数} $$M$$ \text{满足关系：} $$M = 2^k$。
2. **数据引脚（$D_m \sim D_0$）**：
   * 双向三态信号，用于 CPU 与芯片之间传输读出或写入的数据。
   * 数据引脚数 $m$ 决定了存储芯片的位宽（即每个存储单元包含的二进制比特数）。
3. **控制引脚**：
   * **片选信号**：通常记为 $\overline{\text{CS}}$$ \text{（Chip Select）或} $$\overline{\text{CE}}$（Chip Enable），低电平有效。当该引脚为低电平时，芯片被激活，数据引脚退出高阻抗状态；当该引脚为高电平时，芯片处于非选中状态，与总线断开。
   * **读写控制信号**：
     * 单线控制方式：记为 $\text{WE}$$ \text{或} $$R/\overline{\text{W}}$，高电平执行读操作，低电平执行写操作。
     * 双线控制方式：独立引出读使能 $\overline{\text{OE}}$$ \text{（Output Enable）与写使能} $$\overline{\text{WE}}$（Write Enable），均为低电平有效。
   * **DRAM 特有选通信号**：行选通信号 $\overline{\text{RAS}}$$ \text{（Row Address Strobe）与列选通信号} $$\overline{\text{CAS}}$（Column Address Strobe），用于行列地址分时打入。

```text
                  +-----------------------------------+
                  |         半导体存储芯片结构         |
                  |                                   |
CPU 地址总线 ---->| A_{k-1} ~ A_0     (单向输入地址)   |
                  |                                   |
CPU 数据总线 <--->| D_{m-1} ~ D_0     (双向三态数据)   |
                  |                                   |
CPU 片选译码 ---->| /CS 或 /CE        (低电平选中)     |
CPU 读写控制 ---->| /WE 或 R//W       (读写模式切换)   |
                  +-----------------------------------+
```

### 2. DRAM 行列地址引脚复用技术

静态随机存储器（SRAM）与动态随机存储器（DRAM）在引脚设计上存在重要差异：

1. **SRAM 的地址引脚**：
   * 若容量为 $M = 2^k$$ \text{个单元，需引出} $$k$ 根地址引脚，地址信号一次性全部送达芯片。
2. **DRAM 的地址引脚复用机制**：
   * 现代大容量 DRAM 芯片内部存储元排列成二维矩阵（行数 $r$$ \text{、列数} $$c$$ \text{），若容量} $$N = 2^k = 2^r \times 2^c$。
   * 为减少芯片封装引脚数、降低印制电路板布线密度，DRAM 普遍采用**行列地址分时复用**技术。
   * 芯片外部仅引出 $\max(r, c)$$ \text{根物理地址引脚（通常内部设计} $$r \approx c = k/2$$ \text{，因此外部地址引脚数为} $$k/2$ 根）。
   * 读写时，CPU 首先将行地址送至地址引脚，通过 $\overline{\text{RAS}}$$ \text{有效锁存；随后将列地址送至同一批地址引脚，通过} $$\overline{\text{CAS}}$ 有效锁存。
3. **引脚总数计算公式**：
   * **SRAM 芯片**：
     $$ \text{引脚数} = k\ (\text{地址线}) + m\ (\text{数据线}) + 1\ (\overline{\text{CS}}) + 1\ (\overline{\text{WE}}) + 2\ (\text{电源与地}) $$
   * **DRAM 芯片（地址复用）**：
     $$ \text{引脚数} = \lceil k/2 \rceil\ (\text{复用地址线}) + m\ (\text{数据线}) + 1\ (\overline{\text{RAS}}) + 1\ (\overline{\text{CAS}}) + 1\ (\overline{\text{WE}}) + 2\ (\text{电源与地}) $$

### 3. 主存容量扩展的三种模式

当单个存储芯片的字数或位数无法满足系统需求时，必须采用多片芯片进行组合扩展。

#### （1）位扩展（Bit Extension）

* **应用条件**：单片存储芯片的字数满足系统要求，但位宽（数据位数）小于 CPU 数据总线宽度。
* **连接特征**：
  * **地址总线**：CPU 的低位地址线 $A_{k-1} \sim A_0$ 同时并联到所有存储芯片的地址引脚。
  * **片选信号**：所有芯片的片选引脚 $\overline{\text{CS}}$ 并联连接，由同一个系统片选信号驱动，所有芯片同时被选中工作。
  * **读写控制**：所有芯片的 $\overline{\text{WE}}$ 并联连接，同步执行读或写操作。
  * **数据总线**：各芯片的数据引脚分别独立连接到 CPU 数据总线的不同位段。
* **芯片片数计算**：
  $$ \text{N_{\text{位}} = \frac{D_{\text{系统位宽}}}{d_{\text{芯片位宽}}}} $$

```text
【位扩展连接逻辑示意图：以 8K×4 位芯片扩展为 8K×8 位为例】

CPU 地址总线 A12~A0 --------------------+--------------------+
                                       |                    |
                                 +-----+-----+        +-----+-----+
                                 |  芯片 1   |        |  芯片 2   |
                                 |  8K × 4位 |        |  8K × 4位 |
                                 +-----+-----+        +-----+-----+
CPU 读写控制 /WE ----------------------+--------------------+
CPU 片选使能 /CS ----------------------+--------------------+
                                       |                    |
CPU 数据总线 D7~D4 <-------------------+                    |
CPU 数据总线 D3~D0 <----------------------------------------+
```

---

#### （2）字扩展（Word Extension）

* **应用条件**：单片存储芯片的位宽满足系统数据总线宽度，但字数小于系统所需的寻址空间。
* **连接特征**：
  * **数据总线**：所有芯片的数据引脚 $D_{m-1} \sim D_0$ 直接并联到 CPU 数据总线。
  * **低位地址总线**：CPU 地址总线的低 $k$ 位（片内地址）并联到所有芯片的地址引脚。
  * **高位地址总线**：CPU 地址总线的高位（片选地址）输入给外部片选译码电路，译码输出端分别独立连接各芯片的 $\overline{\text{CS}}$ 引脚。任意时刻仅有一片（或一组）芯片被选中。
  * **读写控制**：所有芯片的 $\overline{\text{WE}}$ 并联连接。
* **芯片片数计算**：
  $$ \text{N_{\text{字}} = \frac{M_{\text{系统字数}}}{m_{\text{芯片字数}}}} $$

```text
【字扩展连接逻辑示意图：以 2 片 16K×8 位芯片扩展为 32K×8 位为例】

CPU 地址 A14 -----------------> 译码反相器 (产生 /CS0 与 /CS1)
                                |              |
CPU 地址 A13~A0 ------------+---+----------+   |
                            |   |          |   |
CPU 读写控制 /WE ----------+---+------+   |   |
                            |   |      |   |   |
                      +-----+---+--+ +-+---+---+--+
                      |   芯片 0   | |   芯片 1   |
                      |  16K × 8位 | |  16K × 8位 |
                      |   (/CS0)   | |   (/CS1)   |
                      +-----+------+ +-----+------+
                            |              |
CPU 数据总线 D7~D0 <--------+--------------+
```

---

#### （3）字位同时扩展（Combined Word and Bit Extension）

* **应用条件**：单片存储芯片的字数和位宽均达不到系统需求。
* **设计方法**：
  1. 首先进行位扩展：将 $$ \text{N_{\text{位}}} $$ 片芯片并联构成一个“存储模块组”，使其位宽与数据总线一致；
  2. 随后进行字扩展：将 $$ \text{N_{\text{字}}} $$ 个存储模块组通过高位地址译码进行组选，扩展整个存储器的字容量。
* **芯片总数计算**：
  $$ \text{N_{\text{总}} = N_{\text{字}} \times N_{\text{位}} = \left(\frac{M_{\text{系统字数}}}{m_{\text{芯片字数}}}\right) \times \left(\frac{D_{\text{系统位宽}}}{d_{\text{芯片位宽}}}\right) = \frac{\text{系统总容量（bit）}}{\text{单片容量（bit）}}} $$

```text
【字位同时扩展拓扑结构图：用 4 片 2K×4 位扩展为 4K×8 位】

                 高位地址 A11 (经 1-2 译码)
                       |            |
                 组选 /CS_Group0  组选 /CS_Group1
                   +-------+    +-------+
                   |       |    |       |
                 +---+   +---++---+   +---+
                 |片0|   |片1||片2|   |片3| (每片 2K×4 位)
                 +---+   +---++---+   +---+
                   |       |    |       |
  低位地址 A10~A0 -+-------+----+-------+   (全并联)
  读写控制 /WE   -+-------+----+-------+   (全并联)
                   |       |    |       |
  数据高4位 D7~D4 -+-------|----+-------|   (片0 与 片2 共享)
  数据低4位 D3~D0 ---------+------------+   (片1 与 片3 共享)
```

### 4. 片选控制逻辑与译码机制深度剖析

为了使 CPU 能正确寻址扩展后的各个存储芯片，必须通过高位地址线生成片选信号。片选控制逻辑主要分为线选法与译码片选法。

#### （1）线选法（Line Selection）

* **工作机理**：直接利用 CPU 高位地址线中的某一条单线，分别接到不同存储芯片的片选端 $\overline{\text{CS}}$。当某条高位地址线为低电平（0）时，选中对应芯片。
* **优点**：无需外部译码器件，硬件连接最为简单。
* **致命缺点**：
  1. **地址空间利用率极低**：$k$$ \text{根高位地址线仅能选中} $$k$$ \text{个芯片（或芯片组），而译码法能选} $$2^k$ 个。
  2. **地址空间不连续**：由于每次只能有一根地址线有效为 0，高位地址组合受限，地址空间被切割得支离破碎。
  3. **地址重叠（Address Overlap）**：未连接的高位地址线处于“任意态”（无关态），导致同一个物理存储单元对应多个合法的逻辑地址，极易引发程序总线冲突。

---

#### （2）译码片选法（Decoder Selection）

译码片选法利用译码器（如 74LS138、74LS139）将 $k$$ \text{根高位地址线译码成} $$2^k$ 个相互排斥的低电平输出信号，驱动各芯片的片选端。

* **全译码方式（Full Decoding）**：
  * **机制**：CPU 的全部高位地址线均参与译码（部分作为译码器的选择输入端 $A, B, C$$ \text{，其余高位地址线与 CPU 控制信号接入使能控制端} $$G_1, \overline{G}_{2A}, \overline{G}_{2B}$）。
  * **特性**：每个物理存储单元具有**唯一确定**的主存地址，地址空间完全连续，不存在地址重叠。
* **部分译码方式（Partial Decoding）**：
  * **机制**：仅部分高位地址线参与译码，保留若干高位地址线悬空（未接入任何译码逻辑）。
  * **特性**：未参与译码的高位地址线其电平取 0 或 1 均不影响片选输出，导致同一物理存储单元在不同的高位地址配置下被重复选中，产生**地址重叠（地址镜像）**。

```text
【全译码与部分译码对比分析表】

| 对比维度 | 全译码方式 (Full Decoding) | 部分译码方式 (Partial Decoding) | 线选法 (Line Selection) |
| :--- | :--- | :--- | :--- |
| **高位地址线利用** | 全部参与译码电路 | 仅部分参与，部分悬空 | 单根引脚直接连接片选 |
| **芯片选通能力** | $k$$ \text{根地址线选} $$2^k$$ \text{组 | 受限于参与译码的线数 |} $$k$$ \text{根地址线仅选} $$k$ 组 |
| **地址唯一性** | 地址严格唯一，无重叠 | 存在地址重叠（镜像） | 存在严重地址重叠 |
| **地址空间连续性**| 空间高度规整连续 | 空间离散或分段重叠 | 空间严重离散不连续 |
| **硬件复杂度** | 译码电路稍显复杂 | 译码电路简化 | 无额外硬件成本 |
```

### 5. 编址方式与寻址空间换算精析

考研真题中常通过不同编址方式设置计算陷阱，考生必须熟练掌握以下核心规律：

1. **基本编址规则**：
   * **按字节编址（Byte Addressing）**：每一个独立的物理地址对应 1 个字节（8 位）。计算机系统通常默认采用按字节编址。
   * **按字编址（Word Addressing）**：每一个独立的物理地址对应一个“机器字”。字长可为 16 位、32 位或 64 位。
2. **容量与寻址范围换算公式**：
   * 若主存物理总容量为 $C$$ \text{字节，字长为} $$W$$ \text{位（即} $$W/8$ 字节）：
     $$ \text{按字节编址单元数} = \frac{C\ (\text{字节})}{1\ \text{B}} = C $$
     $$ \text{按字编址单元数} = \frac{C\ (\text{字节})}{(W/8)\ \text{B/字}} $$
   * 若寻址单元数为 $N$，则所需寻址地址线根数为：
     $$K = \log_2 N$$
   * 对应的物理地址寻址范围为：
     $$ \text{0 \sim (N - 1) \quad \text{或写为十六进制：} 0000\dots 0\text{H} \sim (N-1)\text{H}} $$
3. **十六进制地址区间容量计算法则**：
   * 设起始地址为 $\text{Addr}_{\text{start}}$$ \text{，终止地址为} $$\text{Addr}_{\text{end}}$，则该连续区间包含的存储单元数为：
     $$ \text{单元数} = \text{Addr}_{\text{end}} - \text{Addr}_{\text{start}} + 1 $$
   * **十六进制简算技巧**：
     * $100\text{H} = 16^2 = 256$ 单元；
     * $400\text{H} = 2^{10} = 1\text{K}$ 单元；
     * $1000\text{H} = 16^3 = 2^{12} = 4\text{K}$ 单元；
     * $10000\text{H} = 16^4 = 2^{16} = 64\text{K}$ 单元；
     * $100000\text{H} = 16^5 = 2^{20} = 1\text{M}$ 单元。

### 6. 核心易错点与命题陷阱透视

* **陷阱 1：ROM 区与 RAM 区混合编址时盲目加和总容量**  
  系统若指定 ROM 区容量与 RAM 区容量，由于两种芯片的字长和位数规格不同，必须**分别独立计算**所需的 ROM 芯片数与 RAM 芯片数，切忌将两者总容量合并相加后除以某一种芯片容量。
* **陷阱 2：混淆“主存地址空间大小”与“实际主存容量”**  
  CPU 的地址总线位数（MAR 位数）决定了系统的“最大主存地址空间”，而实际安装的主存芯片容量往往小于该空间。主存地址总线位数的设定必须满足最大地址空间的寻址需求。
* **陷阱 3：DRAM 引脚计算遗漏地址复用**  
  在计算 DRAM 芯片引脚数时，若题目明确说明采用行列地址复用，地址引脚数必须减半；但数据引脚数不受地址复用影响，依然由芯片位宽唯一决定。
* **陷阱 4：片选地址区间的边界判定失准**  
  将某地址对应的片内偏移清零即可得到该芯片的起始地址；将片内偏移全置 1 即可得到该芯片的最大结束地址。切勿通过加减单片容量直接在十六进制下生搬硬套。

### 【真题 1】2021 年 408 统考第 15 题 · 按字编址与芯片数计算

**题目**  
某计算机的存储器总线中有 24 位地址线和 32 位数据线，按字编址，字长为 32 位。若 $000000\text{H} \sim 3FFFFF\text{H}$$ \text{为 RAM 区，则需要} $$512\text{K}\times 8$ 位的 RAM 芯片数为（ ）。  
A. 8 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. 16 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 32 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 64  

#### 【解析】
1. **明确编址单位与有效字数**：
   * 题目明确指出系统**按字编址**，字长为 32 位（即 4 字节）。
   * 地址范围为 $000000\text{H} \sim 3FFFFF\text{H}$。
   * 该地址空间包含的存储单元总数为：
     $$ \text{单元数} = 3FFFFF\text{H} - 000000\text{H} + 1 = 400000\text{H} $$
   * 将十六进制转换为十进制/以 2 为底的指数：
     $$ \text{400000\text{H} = 4 \times 16^5 = 2^2 \times 2^{20} = 2^{22} = 4\text{M 个字}} $$
2. **计算 RAM 区总容量**：
   * 每个存储单元为 1 个字（32 位），因此 RAM 区总容量为：
     $$ \text{总容量} = 4\text{M} \times 32\ \text{位} = 2^{22} \times 32\ \text{位} $$
3. **计算单片 RAM 芯片容量及所需片数**：
   * 单片芯片规格为 $$ \text{512\text{K} \times 8\ \text{位} = 2^{19} \times 8\ \text{位}} $$。
   * 所需芯片片数采用字位同时扩展公式计算：
     $$ \text{N = \frac{\text{系统总容量}}{\text{单片芯片容量}} = \frac{4\text{M} \times 32\ \text{位}}{512\text{K} \times 8\ \text{位}} = \left(\frac{4\text{M}}{512\text{K}}\right) \times \left(\frac{32\ \text{位}}{8\ \text{位}}\right) = 8 \times 4 = 32\ \text{片}} $$
4. **干扰项深度剖析**：
   * 选项 A（8 片）：仅计算了字扩展倍数（$4\text{M}/512\text{K} = 8$），忽略了位扩展需由 8 位扩展至 32 位（4 倍）；
   * 选项 B（16 片）：误将系统当成 16 位字长进行计算；
   * 选项 D（64 片）：误将按字编址当作按字节编址，导致总容量错误放大为原来的 4 倍（即多乘了 2）。

**正确答案**：**C**

### 【真题 2】2021 年统考考点题 · 存储芯片扩展与片选地址位数推导

**题目**  
假定用若干个 $2\text{K} \times 4$$ \text{位的芯片组成一个} $$8\text{K} \times 8$ 位的存储器，则地址线中用于选片的位数为多少位？共需要多少片芯片？（ ）  
A. 1 位，4 片 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. 2 位，8 片 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 3 位，8 片 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 2 位，4 片  

#### 【解析】
1. **计算所需芯片总数**：
   * 目标存储器规格为 $8\text{K} \times 8$$ \text{位；单片芯片规格为} $$2\text{K} \times 4$ 位。
   * 芯片总数：
     $$ \text{N_{\text{总}} = \frac{8\text{K} \times 8\ \text{位}}{2\text{K} \times 4\ \text{位}} = \left(\frac{8\text{K}}{2\text{K}}\right) \times \left(\frac{8}{4}\right) = 4 \times 2 = 8\ \text{片}} $$
2. **分析扩展架构与组数**：
   * **位扩展**：每组由 2 片 $2\text{K} \times 4$$ \text{位芯片并联，构成一个} $$2\text{K} \times 8$ 位的基本存储模块组；
   * **字扩展**：整个存储器需要 $8\text{K} \times 8$$ \text{位，因此需要} $$8\text{K} / 2\text{K} = 4$ 个基本存储模块组。
3. **推导片选（组选）地址位数**：
   * 存储器总容量为 $8\text{K}$$ \text{单元，总地址线数为} $$\log_2 (8\text{K}) = \log_2 (2^{13}) = 13$$ \text{根（即} $$A_{12} \sim A_0$）；
   * 单片芯片容量为 $2\text{K}$$ \text{单元，片内地址线数为} $$\log_2 (2\text{K}) = \log_2 (2^{11}) = 11$$ \text{根（即} $$A_{10} \sim A_0$）；
   * 剩余的高位地址线作为组片选信号：
     $$ \text{片选地址位数} = 13 - 11 = 2\ \text{位（即 } A_{12}, A_{11}\text{）} $$
   * 2 位高位地址线经 $2-4$ 译码器译码后，产生 4 个独立的组片选信号，分别连接 4 组模块。

**正确答案**：**B**

### 【真题 3】2018 年统考考点题 · 芯片位扩展与片选控制逻辑

**题目**  
某计算机主存地址位数为 32 位，按字节编址。假定主存选用 4 片 $1\text{G}\times 8$ 位的 DRAM 芯片构成，并采用位扩展方式直接连接到 32 位数据总线。下列关于该主存系统的叙述中，正确的是（ ）。  
A. 4 片芯片需要 2 位高位地址线进行片选译码  
B. 每片芯片的地址引脚数为 30 根（不考虑地址复用）  
C. 4 片芯片的片选信号引脚必须独立分别控制  
D. 该主存系统的总容量为 4GB，芯片之间采用字扩展连接  

#### 【解析】
1. **位扩展工作机理剖析**：
   * 题目指出“选用 4 片 $1\text{G}\times 8$ 位的 DRAM 芯片直接连接到 32 位数据总线”。
   * 4 片 8 位的芯片通过数据线并联，数据位宽扩展为 $4 \times 8 = 32$$ \text{位，字数仍为} $$1\text{G}$。
   * 总存储容量为 $$ \text{1\text{G} \times 32\ \text{位} = 1\text{G} \times 4\ \text{B} = 4\text{GB}} $$。由于 CPU 数据总线为 32 位，4 片芯片同时提供一个 32 位的机器字（包含 4 个字节）。
2. **选项逐项核验**：
   * **A 项错误**：在位扩展结构中，4 片芯片属于同一组，它们同时被选中、同时工作，无需高位地址线译码选片，其片选信号并联在一起；
   * **B 项正确**：每片芯片的容量为 $1\text{G} = 2^{30}$$ \text{单元，若不考虑地址引脚复用，内部地址线数确实为} $$\log_2(1\text{G}) = 30$ 根；
   * **C 项错误**：位扩展要求所有芯片同时激活，片选引脚 $\overline{\text{CS}}$ 必须连接到同一个片选控制信号，不能独立分别控制；
   * **D 项错误**：芯片之间将数据位从 8 位拼装成 32 位，属于典型的位扩展，而非字扩展。

**正确答案**：**B**

### 【真题 4】2017 年统考考点题 · Flash 存储芯片容量与寻址范围

**题目**  
某数码相机内存卡采用双片 $16\text{G}\times 1$ 位的 Flash 芯片组成，容量为 4GB。若该内存卡按字（32 位）编址，则寻址范围是（ ）。  
A. $0 \sim 256\text{M}-1$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. $0 \sim 512\text{M}-1$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. $0 \sim 1\text{G}-1$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. $0 \sim 2\text{G}-1$  

#### 【解析】
1. **计算内存卡总存储容量**：
   * 双片 $16\text{G}\times 1$ 位的芯片，总比特数为：
     $$2 \times 16\text{Gb} = 32\text{Gb}$$
   * 转换为字节数：
     $$32\text{Gb} = \frac{32}{8}\text{GB} = 4\text{GB}$$
2. **计算按字编址的存储单元数**：
   * 系统规定按字编址，字长为 32 位（即 4 字节）。
   * 存储单元总数（寻址字数）：
     $$ \text{N_{\text{字}} = \frac{\text{总容量（字节）}}{\text{字长（字节）}} = \frac{4\text{GB}}{4\text{B}} = 1\text{G 个字} = 2^{30}\ \text{个字}} $$
3. **确定寻址范围**：
   * 寻址单元编号从 0 开始连续编号，因此物理寻址范围为：
     $$0 \sim (2^{30} - 1) \implies 0 \sim 1\text{G}-1$$
4. **干扰项剖析**：
   * 选项 A（$0 \sim 256\text{M}-1$）：误将 Flash 芯片容量误当作单片且未乘双片，或者误除以了更高字长；
   * 选项 B（$0 \sim 512\text{M}-1$$ \text{）：只计算了一片} $$16\text{Gb}$ 芯片对应的字数；
   * 选项 D（$0 \sim 2\text{G}-1$）：误按 16 位字长进行换算。

**正确答案**：**C**

### 【真题 5】2016 年 408 统考第 16 题 · 地址空间划分与 SRAM 芯片数计算

**题目**  
某存储器容量为 64KB，按字节编址，地址 $4000\text{H} \sim 5FFF\text{H}$$ \text{为 ROM 区，其余为 RAM 区。若采用} $$8\text{K}\times 4$ 位的 SRAM 芯片进行设计，则需要该芯片的数量是（ ）。  
A. 7 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. 8 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. 14 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. 16  

#### 【解析】
1. **计算 ROM 区容量**：
   * ROM 区地址区间为 $4000\text{H} \sim 5FFF\text{H}$；
   * 包含的字节数为：
     $$5FFF\text{H} - 4000\text{H} + 1 = 2000\text{H}$$
   * 将十六进制 $2000\text{H}$ 转换为十进制容量：
     $$2000\text{H} = 2 \times 16^3 = 2 \times (2^4)^3 = 2 \times 2^{12} = 2^{13}\ \text{B} = 8\text{KB}$$
2. **计算 RAM 区容量**：
   * 存储器总容量为 $64\text{KB}$，减去 ROM 区容量即为 RAM 区容量：
     $$ \text{RAM 区容量} = 64\text{KB} - 8\text{KB} = 56\text{KB} $$
3. **计算所需 SRAM 芯片数量**：
   * 本题采用 $8\text{K}\times 4$ 位的 SRAM 芯片构建 RAM 区；
   * 单片 SRAM 芯片的容量为：
     $$ \text{8\text{K} \times 4\ \text{位} = 8\text{K} \times 0.5\ \text{B} = 4\text{KB}} $$
   * 所需 SRAM 芯片数量：
     $$ \text{N = \frac{\text{RAM 区总容量}}{\text{单片容量}} = \frac{56\text{KB}}{4\text{KB}} = 14\ \text{片}} $$
   * （注：具体扩展时，每 2 片进行位扩展构成 $8\text{KB}$$ \text{模块，共需 7 组，即} $$7 \times 2 = 14$ 片）。
4. **干扰项深度剖析**：
   * 选项 A（7 片）：只算了模块组数，漏乘了位扩展所需的 2 片；
   * 选项 D（16 片）：将整个 $64\text{KB}$$ \text{全部用 SRAM 芯片构建（} $$64 / 4 = 16$），忽略了 ROM 区占用的空间；
   * 选项 B（8 片）：误将 ROM 区容量或某一组配置代入。

**正确答案**：**C**

### 【真题 6】2023 年 408 统考第 15 题 · 高位地址译码与 ROM/RAM 边界判定

**题目**  
某计算机的 CPU 有 30 根地址线，按字节编址，CPU 和主存芯片连接时，要求主存芯片占满所有可能存储地址空间，并且 RAM 区和 ROM 区所分配的容量大小比为 $3:1$。若 RAM 在连续低地址区，ROM 在连续高地址区，则 ROM 的地址范围是（ ）。  
A. $00000000\text{H} \sim 0FFFFFFF\text{H}$  
B. $10000000\text{H} \sim 2FFFFFFF\text{H}$  
C. $30000000\text{H} \sim 3FFFFFFF\text{H}$  
D. $40000000\text{H} \sim 4FFFFFFF\text{H}$  

#### 【解析】
1. **分析地址总空间与高位二进制位**：
   * CPU 拥有 30 根地址线（$A_{29} \sim A_0$），按字节编址，系统的最大寻址空间为：
     $$2^{30}\ \text{B} = 1\text{GB}$$
   * 整个 1GB 地址空间对应的十六进制范围为：
     $$00000000\text{H} \sim 3FFFFFFF\text{H}$$
     *验证*：最高地址即 30 位全 1，二进制为 $$ \text{\underbrace{11}_{3}\ \underbrace{1111\dots 1111}_{28\text{个}1} = 3FFFFFFF\text{H}} $$。
2. **容量分配与高位地址切分**：
   * RAM 与 ROM 容量之比为 $3:1$，且填满全部空间。
   * 因此，RAM 区占据前 $3/4$$ \text{（容量为} $$768\text{MB}$$ \text{），ROM 区占据后} $$1/4$$ \text{（容量为} $$256\text{MB}$）。
   * 考虑最高两位地址线 $A_{29}A_{28}$ 的四种编码状态：
     * $A_{29}A_{28} = 00$$ \text{：对应} $$00000000\text{H} \sim 0FFFFFFF\text{H}$（容量 256MB，属于 RAM）
     * $A_{29}A_{28} = 01$$ \text{：对应} $$10000000\text{H} \sim 1FFFFFFF\text{H}$（容量 256MB，属于 RAM）
     * $A_{29}A_{28} = 10$$ \text{：对应} $$20000000\text{H} \sim 2FFFFFFF\text{H}$（容量 256MB，属于 RAM）
     * $A_{29}A_{28} = 11$$ \text{：对应} $$30000000\text{H} \sim 3FFFFFFF\text{H}$（容量 256MB，属于 ROM）
3. **确定 ROM 区起始与终止地址**：
   * RAM 区占据低地址 $00000000\text{H} \sim 2FFFFFFF\text{H}$；
   * ROM 区占据高地址 $30000000\text{H} \sim 3FFFFFFF\text{H}$。

**正确答案**：**C**

### 【真题 7】2010 年 408 统考第 15 题 · 芯片内偏移与最小边界地址定位

**题目**  
假定用若干个 $2\text{K}\times 4$$ \text{位的芯片组成一个} $$8\text{K}\times 8$$ \text{位的存储器，则地址} $$0\text{B}1\text{FH}$ 所在芯片的最小地址是（ ）。  
A. $0000\text{H}$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; B. $0600\text{H}$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; C. $0700\text{H}$ &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; D. $0800\text{H}$  

#### 【解析】
1. **分析芯片分组结构与寻址线分配**：
   * 组成 $8\text{K}\times 8$$ \text{位存储器，共需} $$\frac{8\text{K}\times 8}{2\text{K}\times 4} = 8$ 片芯片；
   * 每 2 片通过位扩展组成一个 $2\text{K}\times 8$ 位的模块组，共分为 4 组（组 0、组 1、组 2、组 3）；
   * 单片容量为 $2\text{K}$$ \text{单元，片内地址占用 11 根地址线（} $$A_{10} \sim A_0$）；
   * $2\text{K} = 2^{11}\ \text{B} = 0800\text{H}$$ \text{（即每个模块组覆盖的物理跨度为} $$0800\text{H}$）。
2. **划分各组的连续物理地址范围**：
   * **第 0 组**：$0000\text{H} \sim (0000\text{H} + 0800\text{H} - 1) = 0000\text{H} \sim 07FF\text{H}$
   * **第 1 组**：$0800\text{H} \sim (0800\text{H} + 0800\text{H} - 1) = 0800\text{H} \sim 0FFF\text{H}$
   * **第 2 组**：$1000\text{H} \sim (1000\text{H} + 0800\text{H} - 1) = 1000\text{H} \sim 17FF\text{H}$
   * **第 3 组**：$1800\text{H} \sim (1800\text{H} + 0800\text{H} - 1) = 1800\text{H} \sim 1FFF\text{H}$
3. **定位目标地址**：
   * 所给地址为 $0\text{B}1\text{FH}$。
   * 显然，$0800\text{H} \le 0\text{B}1\text{FH} \le 0FFF\text{H}$，属于**第 1 组**芯片；
   * 该组芯片所覆盖的最小地址即为该段区间的起始地址 $0800\text{H}$。
4. **二进制位分解验证法**：
   * 将 $0\text{B}1\text{FH}$$ \text{转为二进制：} $$0000\ 1011\ 0001\ 1111\text{B}$；
   * 低 11 位（$A_{10} \sim A_0$）为片内偏移：`011 0001 1111`；
   * 高位（$A_{12} A_{11}$）为组片选：`01`（对应第 1 组）；
   * 将片内偏移全置 0，高位保持 `01`：$0000\ 1000\ 0000\ 0000\text{B} = 0800\text{H}$。

**正确答案**：**D**

## 四、 综合大题应用与考查拓展

在 408 统考综合应用题（第 43 题或第 44 题）中，主存容量扩展常与 CPU 数据通路、Cache 映射、虚拟存储机制紧密结合命题。

### 1. 存储芯片与 CPU 接口规范设计

综合大题常要求考生画出或补充 CPU 与主存芯片的硬件连接图，核心规范包括：

1. **地址引脚连接**：
   * CPU 低位地址总线（片内寻址）直接连接所有存储芯片的片内地址引脚。
   * CPU 高位地址总线连接译码器输入端，译码器各输出端产生独立的组片选信号 $\overline{Y}_i$$ \text{，分别连接到各芯片的} $$\overline{\text{CS}}$ 引脚。
2. **数据引脚连接**：
   * 位扩展的各片芯片数据线分别接 CPU 数据总线的高低位段（如高 8 位 $D_{15}\sim D_8$$ \text{与低 8 位} $$D_7\sim D_0$）。
   * 字扩展的各组芯片对应数据位并联接入 CPU 数据总线。
3. **控制信号与译码使能**：
   * CPU 的访存使能信号 $\overline{\text{MREQ}}$$ \text{（主存请求，低有效）通常接入译码器的低电平有效使能端（如} $$\overline{G}_{2A}$），确保 CPU 仅在访存时激活片选信号，避免 I/O 操作时误选存储器。
   * CPU 的读写控制线 $\overline{\text{WE}}$$ \text{或} $$R/\overline{\text{W}}$ 直接并联送入各 RAM 芯片的读写控制引脚（ROM 芯片无写控制引脚）。

```text
【典型 74LS138 译码器与 CPU、主存芯片接线规范图】

                   +------------------+
                   |     74LS138      |
CPU 地址 A15 ----->| A2 (输入高位)    |
CPU 地址 A14 ----->| A1              |
CPU 地址 A13 ----->| A0 (输入低位)    |
                   |                  |
CPU MREQ (低) ---->| /G2A (使能低有效)|-----> /Y0 (输出低有效) ---> 模块组0 /CS
高电平 VCC (+5V) ->| G1   (使能高有效)|-----> /Y1 (输出低有效) ---> 模块组1 /CS
CPU 地址 A16(低) ->| /G2B (使能低有效)|-----> /Y2 (输出低有效) ---> 模块组2 /CS
                   +------------------+
```

### 2. 跨模块知识联动分析

1. **联动 1：与 Cache-主存映射联动**
   * 主存通过字扩展增大容量后，物理地址总位数增加；
   * 若 Cache 块大小和组数保持不变，主存地址中的“块内地址”与“Cache 组号”位数保持不变，主存扩展增加的高位地址将全部并入 **Tag（主存标记）** 位数中；
   * 每增加 1 倍主存容量（即增加 1 根地址线），Cache 行中的 Tag 字段长度需增加 1 位。
2. **联动 2：与分页虚拟存储器联动**
   * 主存物理地址由“物理页号（实页号）+ 页内偏移”构成；
   * 页内偏移位数由“页面大小”唯一决定；
   * 主存容量通过扩展扩大后，物理地址增加的位数直接反映在**实页号**的长度上，从而影响页表项中实页号字段的位宽。
3. **联动 3：与多体交叉编址流水线联动**
   * 高位多体交叉编址本质上是按字扩展方式工作（高位选模块，低位选单元），无法实现流水线并行存取；
   * 低位多体交叉编址（低位选模块，高位选单元）可在每个连续时钟周期启动一个存储体，实现流水线并发，大幅提高主存带宽。

---

### 3. 大题标准答题模板与得分要点

* **题型一：求解地址范围与芯片片数**
  * *步骤 1*：列出 ROM 区与 RAM 区各自的起始与结束十六进制地址；
  * *步骤 2*：计算容量 $\text{Addr}_{\text{end}} - \text{Addr}_{\text{start}} + 1$$ \text{，换算为二进制幂次（如} $$8\text{KB} = 2^{13}\ \text{B}$）；
  * *步骤 3*：根据单片芯片容量列出除法算式，分别写出 ROM 芯片数与 RAM 芯片数；
  * *踩分点*：算式必须包含单位（位/字节）；严禁合并算式后直接写结果。
* **题型二：译码电路与逻辑表达式设计**
  * *步骤 1*：写出各片选输出端有效时的二进制高位地址取值；
  * *步骤 2*：明确指出 74LS138 的输入端 $A_2, A_1, A_0$$ \text{以及使能端} $$G_1, \overline{G}_{2A}, \overline{G}_{2B}$ 分别接 CPU 的哪几位地址线和控制线；
  * *踩分点*：使能端的低电平有效信号与高电平有效信号切勿接反。

## 五、 考点速记清单

### 1. 核心计算公式汇总

1. **芯片总数公式**：
   $$ \text{N_{\text{总}} = \left(\frac{M_{\text{系统字数}}}{m_{\text{芯片字数}}}\right) \times \left(\frac{D_{\text{系统位宽}}}{d_{\text{芯片位宽}}}\right) = N_{\text{字}} \times N_{\text{位}}} $$
2. **寻址空间与地址线公式**：
   $$ \text{寻址单元数 } N = 2^k \implies \text{地址线数 } k = \log_2 N $$
   $$ \text{按字编址寻址单元数} = \frac{\text{系统总字节数}}{\text{机器字长（字节）}} $$
3. **DRAM 地址复用引脚公式**：
   $$ \text{物理地址引脚数} = \lceil k/2 \rceil \quad (k = \log_2 N) $$
4. **十六进制地址容量公式**：
   $$ \text{容量} = \text{末地址} - \text{首地址} + 1 $$

### 2. 扩展模式快速判别法则

```text
       系统需求与单片芯片规格对比
                  |
    +-------------+-------------+
    |                           |
字数相同，位数不足          位数相同，字数不足
    |                           |
【位扩展】                  【字扩展】
- 地址线全并联              - 数据线全并联
- 片选线全并联              - 高位地址进译码器产生各组 /CS
- 各芯片接不同数据位段      - 低位地址全并联接芯片地址引脚
    |                           |
    +-------------+-------------+
                  |
            字数、位数均不足
                  |
         【字位同时扩展】
         - 先位扩展成组
         - 再字扩展选组
```

### 3. 极速避坑黄金要诀

* **两区独立**：ROM 区、RAM 区规格各异，容量与芯片片数必须独立计算，不可混为一谈。
* **字节区分**：按字编址先除以字长字节数，切勿直接用字节地址线寻址字单元。
* **复用减半**：DRAM 地址引脚分行列时减半，数据引脚与控制引脚绝不减半。
* **低电有效**：片选 $\overline{\text{CS}}$$ \text{与写使能} $$\overline{\text{WE}}$ 绝大多数为低电平有效，译码输出同样是低电平有效。
* **最小地址**：找芯片最小地址，直接将片内偏移全清 0；找最大地址，直接将片内偏移全置 1。
